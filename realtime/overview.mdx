Realtime pushes updates to your app as they happen: a chat message arrives, a teammate joins a document, a record changes. You use it through `pawabase.realtime` (`pb.realtime` in Python).

You **set up** who may join and send in Studio, and **watch** it live there. Your app **uses** channels.

## A first taste

<CodeGroup>
```typescript TypeScript
const room = pawabase.realtime.channel("chat:lobby");
room.onEvent("message", (m) => console.log(m.from, m.payload));

await room.subscribe();
await room.send("message", { text: "hello" });
```

```python Python
import asyncio
from pawabase import AsyncPawabase

async def main():
    async with AsyncPawabase(url, key) as pb:
        room = pb.realtime.channel("chat:lobby")
        room.on("message", lambda m: print(m["from"], m["payload"]))
        await room.subscribe()
        await room.send("message", {"text": "hello"})
        await asyncio.sleep(5)

asyncio.run(main())
```
</CodeGroup>

<Note>
In Python, live channels need the async client and `pip install "pawabase[realtime]"`. Publishing and reading history or presence also work on the normal client.
</Note>

## The ideas

| Idea | Meaning |
| --- | --- |
| Channel | A named stream such as `chat:lobby` or `order:42`. Everyone subscribed receives what is sent to it |
| Channel rule | A pattern (`chat:*`) with who may join, who may send, and whether messages are kept |
| Event | A label on a message (`message`, `typing`). Listen to one or to all |
| Presence | Who is on a channel right now, with a little data about each |
| History | Recent messages a new or reconnecting client can load |
| Record changes | Automatic messages when records are created, updated or deleted |

## Choosing a feature

| You want | Use |
| --- | --- |
| Chat, a game, collaborative cursors | A channel with `send`, and presence |
| A list that updates when rows change | [Live records](/realtime/record-changes) |
| A notification from your backend | [Publish from your server](/realtime/publishing) |
| One-way live updates, no WebSocket | A [stream](/realtime/connection#one-way-streams) |
