Realtime lets your app react the moment something happens, without polling: a chat message arrives, a teammate joins a document, a record changes. You use it through `pawabase.realtime` in TypeScript or `pb.realtime` in Python.

## Get started

<CodeGroup>
```typescript TypeScript
import { createClient } from "@pawabase/client";

const pawabase = createClient({ url: "https://api.example.com", apiKey: "pb_pk_…" });

const room = pawabase.realtime.channel("chat:lobby");
room.onEvent("message", (m) => console.log(m.from, m.payload));

await room.subscribe();
await room.send("message", { text: "hello" });
```

```python Python
import asyncio
from pawabase import AsyncPawabase

async def main():
    async with AsyncPawabase("https://api.example.com", "pb_pk_…") as pb:
        room = pb.realtime.channel("chat:lobby")
        room.on("message", lambda m: print(m["from"], m["payload"]))

        await room.subscribe()
        await room.send("message", {"text": "hello"})
        await asyncio.sleep(5)

asyncio.run(main())
```
</CodeGroup>

<Note>
Python's live channels need the async client and the extra package: `pip install "pawabase[realtime]"`. Publishing, reading history and reading presence also work on the normal synchronous client.
</Note>

The channel must be allowed by your project's [channel rules](/realtime/channel-rules). By default a signed-in user may subscribe and publish.

## The ideas

| Idea | Meaning |
| --- | --- |
| Channel | A named stream such as `chat:lobby` or `order:42`. Anyone subscribed receives what is sent to it. |
| Event | A label on a message (`message`, `typing`, `moved`). Handlers can listen to one event or all of them. |
| Presence | Who is on a channel right now, with a little data about each, like a name or a cursor colour. |
| History | A short backlog of recent messages that a new or reconnecting subscriber can read. |
| Record changes | Automatic messages when a record is created, updated or deleted, sent only to people allowed to read it. |

## Which one to use

| You want | Use |
| --- | --- |
| A chat, a game, a collaborative cursor | Channels with `send` and presence |
| A list that updates when rows change | [Record changes](/realtime/record-changes) |
| A notification from your backend to users | [Server publish](/realtime/publishing) |
| Live updates in an environment without WebSockets | A [one-way stream](/realtime/connection#one-way-streams) |
