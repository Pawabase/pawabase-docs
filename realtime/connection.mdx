The first `subscribe()` opens a WebSocket. The client keeps it healthy: it sends heartbeats, reconnects after a drop and rejoins your channels. You rarely need more than the status.

## Status

<CodeGroup>
```typescript TypeScript
pawabase.realtime.status;   // "idle" | "connecting" | "open" | "reconnecting" | "closed"

const stop = pawabase.realtime.onStatusChange((status) => {
  offlineBanner.hidden = status === "open";
});
```

```python Python
room.subscribed                              # True while joined
room.on("closed", lambda reason: show_offline())
```
</CodeGroup>

Show a small "reconnecting" hint when it is not `open`. Channels rejoin by themselves.

## Open and close

<CodeGroup>
```typescript TypeScript
await pawabase.realtime.connect();
pawabase.realtime.disconnect();      // close and stop reconnecting
```

```python Python
await pb.realtime.connect()
await pb.realtime.close()
```
</CodeGroup>

Disconnect when you discard a client, for example on sign-out, so timers stop. In Python, `async with AsyncPawabase(...)` does it for you.

## Options (TypeScript)

```typescript
const pawabase = createClient({
  url, apiKey,
  realtime: {
    heartbeatSeconds: 25,
    reconnect: { baseDelayMs: 500, maxDelayMs: 15_000, maxAttempts: 20 },
  },
});
```

| Option | Default | Meaning |
| --- | --- | --- |
| `heartbeatSeconds` | 25 | Ping interval. A connection that stays silent for two intervals is replaced |
| `ackTimeoutMs` | 10000 | How long to wait for the server to accept a request |
| `connectTimeoutMs` | 10000 | How long to wait for the connection to open |
| `reconnect` | on | Backoff settings, or `false` to stay closed after a drop |
| `webSocket` | built in | A WebSocket class, for older Node versions: pass `ws` |

## One-way streams

If you only listen, such as a dashboard or a server process, use Server-Sent Events over plain HTTP. There is no socket to manage and it works through strict proxies.

<CodeGroup>
```typescript TypeScript
for await (const frame of pawabase.realtime.stream(["chat:lobby", "order:42"])) {
  if (frame.type === "message") show(frame.payload);
}
```

```python Python
for frame in pb.realtime.sse(["chat:lobby", "order:42"]):
    if frame["type"] == "message":
        show(frame["payload"])
```
</CodeGroup>

Up to 20 channels per stream. To send, use `publish`:

<CodeGroup>
```typescript TypeScript
await pawabase.realtime.publish("chat:lobby", "message", { text: "hi" });
```

```python Python
pb.realtime.publish("chat:lobby", "message", {"text": "hi"})
```
</CodeGroup>

`publish` needs no open connection, so a server can use it to push to everyone on a channel (`from` is then the user, or `"server"` with a secret key).

## What can go wrong

| Situation | What you see |
| --- | --- |
| A rule refuses you | `subscribe()` or `send()` throws `RealtimeError` |
| The connection drops | Status becomes `reconnecting`; channels emit `closed`, then rejoin |
| Wrong key or project | The connection closes and does not retry |
