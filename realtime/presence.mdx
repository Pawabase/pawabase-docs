title: "Presence"
description: "Show who is on a channel, with a name or colour for each, and react as people join and leave."

---

Presence answers "who is here right now?" Each person on a channel can attach small details, like a name or a colour, and everyone sees them update live. Entries disappear when someone disconnects.

An administrator switches presence on for a channel pattern in the dashboard under **Realtime**.

## Join with details

<CodeGroup>
```typescript TypeScript
const doc = pawabase.realtime.channel("doc:abc", { presence: { name: "Ada", color: "#2dd4bf" } });

doc.on("presence", ({ joins, leaves, members }) => renderAvatars(members));

await doc.subscribe();
doc.presenceState();     // everyone here now
```

```python Python
doc = pb.realtime.channel("doc:abc", presence={"name": "Ada", "color": "#2dd4bf"})
doc.on_presence(lambda joins, leaves: render_avatars(doc.presence_state()))
await doc.subscribe()
```
</CodeGroup>

Each member has:

| Field | Meaning |
| --- | --- |
| `user_id` | The signed-in user's id, or `null` for an anonymous visitor |
| `meta` | The details that person attached |
| `presence_ref` | An id for this connection. One user on two devices appears twice |
| `online_at` | When they joined |

Group by `user_id` to show one avatar per person.

## Update your details

```typescript
await doc.track({ name: "Ada", color: "#2dd4bf", page: "settings" });
```

Subscribe first. Keep presence small and long-lived. For fast things like a cursor position or "typing…", send a message instead:

```typescript
input.addEventListener("input", () => doc.send("typing", { on: true }));
doc.onEvent("typing", (m) => showTyping(m.from));
```

## Read the roster without joining

<CodeGroup>
```typescript TypeScript
const members = await pawabase.realtime.presence("doc:abc");
```

```python Python
members = pb.realtime.presence("doc:abc")
```
</CodeGroup>

Useful for "3 people viewing" counters outside the channel itself.
