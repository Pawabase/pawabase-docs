Presence answers "who is here right now?". Each person on a channel can attach small pieces of data, such as a display name, a colour or which page they are on. Everyone else sees it update live. It is removed automatically when someone disconnects.

Presence is turned on per channel by its [rule](/realtime/channel-rules) (`presence: true`).

## Join with presence data

<CodeGroup>
```typescript TypeScript
const room = pawabase.realtime.channel("doc:abc", { presence: { name: "Ada", color: "#2dd4bf" } });

room.on("presence", ({ joins, leaves, members }) => {
  renderAvatars(members);
});

await room.subscribe();
console.log(room.presenceState());   // everyone here now
```

```python Python
room = pb.realtime.channel("doc:abc", presence={"name": "Ada", "color": "#2dd4bf"})

room.on_presence(lambda joins, leaves: render_avatars(room.presence_state()))

await room.subscribe()
print(room.presence_state())
```
</CodeGroup>

Each member looks like this:

| Field | Meaning |
| --- | --- |
| `user_id` | The signed-in user's id, or `null` for an anonymous visitor |
| `meta` | The data that person attached |
| `presence_ref` | An id for this connection. One user in two tabs has two |
| `online_at` | When they joined |

The presence callback receives who `joins`, who `leaves`, and (in TypeScript) all `members` after the change.

## Update your presence

Call `track` to change what others see, for example as the user moves between pages:

<CodeGroup>
```typescript TypeScript
await room.track({ name: "Ada", color: "#2dd4bf", page: "settings" });
```

```python Python
await room.track({"name": "Ada", "color": "#2dd4bf", "page": "settings"})
```
</CodeGroup>

Subscribe first. Keep presence data small; send frequent things like cursor positions as messages on the channel, not as presence.

## Typing indicators and cursors

Presence is for state that lasts. For short-lived signals use `send`:

```typescript
input.addEventListener("input", () => room.send("typing", { on: true }));
room.onEvent("typing", (m) => showTyping(m.from));
```

## Read the roster without joining

From a server, or anywhere you only need a count:

<CodeGroup>
```typescript TypeScript
const members = await pawabase.realtime.presence("doc:abc");
```

```python Python
members = pb.realtime.presence("doc:abc")      # works on the synchronous client too
```
</CodeGroup>

## Good to know

- The same person on two devices appears twice, with different `presence_ref` values. Group by `user_id` to show one avatar.
- Presence is accurate while people are connected. If a connection drops without closing, the entry is removed after a short heartbeat timeout.
- Presence does not authenticate who is in the data you show. Channel rules decide who may join.
