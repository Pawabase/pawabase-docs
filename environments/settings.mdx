Open **Settings** in an environment. It has five pages.

## General

Defaults your flows, schedules and mail templates read.

| Setting | What it does |
| --- | --- |
| **Description** | A note for your team, such as "Customer-facing production data". |
| **Timezone** | Schedules and emails use it. |
| **Currency** and **Language** | Defaults that your templates can read. |
| **Default environment** | Make this the project's environment that answers requests that name none. Each project has its own. |

## App details

How your app introduces itself in the emails it sends.

| Setting | Where it shows |
| --- | --- |
| **App name** | Available to every email template as `{{ app.name }}` |
| **Support email** | Where replies go; templates can show it as `{{ app.support_email }}` |
| **Postal address** | Footers. Many countries require one in marketing mail. |
| **Website** | Links in your emails |

## API access

Who may call your API. Changes apply within about 30 seconds.

| Setting | What it does |
| --- | --- |
| **Publish the API reference** | Anyone can read your generated API documentation. You can always see it in Studio. |
| **Websites allowed to call it** | Sites that may use a publishable key from JavaScript, like `https://app.example.com`. Leave empty to allow any site. |
| **Servers allowed to use secret keys** | When set, secret keys work only from these addresses or ranges. Publishable keys are not affected. Leave empty to allow any address. |

<Warning>
Make sure your own servers are on the **Servers allowed** list before you save. Secret-key requests from anywhere else are refused until you change it. Studio is not affected.
</Warning>

### Maintenance mode

Tell your users you are working on things without taking anything down. While it is on:

- Your API answers "try again shortly" (503) with your **message** and how long to wait, instead of reaching your data.
- **Keep your servers working** lets requests with a secret key still through, so your scripts and back office keep running.

## API keys

Create, rotate and revoke keys. See [API keys](/environments/api-keys).

## Environment

Export or import this environment's settings, or delete the environment.

- **Export and import** moves settings between environments. Importing fills the form; nothing changes until you review it and press **Save**.
- **Delete** removes the environment's data, keys, secrets and users for good. You type its name to confirm. It is marked for deletion and disappears shortly after.

<Warning>
Deleting an environment cannot be undone. Take a [backup](/backups/overview) first if there's any chance you need it.
</Warning>
