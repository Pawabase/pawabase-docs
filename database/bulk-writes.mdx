## `createMany`

<CodeGroup>
```typescript TypeScript
const { created, failed } = await pawabase.from("tasks").createMany(
  [{ title: "One" }, { title: "Two" }, { title: "" }],
  { concurrency: 5, stopOnError: false },
);

created.length;      // 2
for (const f of failed) console.log("row", f.index, "failed:", f.error);
```

```python Python
result = pb.from_("tasks").create_many([{"title": "One"}, {"title": "Two"}, {"title": ""}], stop_on_error=False)
result.created      # the saved records
result.failed       # [{index, error}]
```
</CodeGroup>

It sends several creates in parallel and tells you which succeeded and which failed (with the row's position), so one bad row doesn't lose the rest. It is **not one transaction**: if you need all-or-nothing, use a [flow or route](/logic/overview) that does the writes together.

| Option | Meaning |
| --- | --- |
| `concurrency` | How many requests at once. Default 5 |
| `stopOnError` (`stop_on_error`) | Stop sending more after the first failure |

In Python the async client runs rows concurrently (`concurrency=` there); the sync client sends them in order.

## Update or delete many

Query, then act on each:

```typescript
const { data } = await pawabase.from("tasks").eq("done", true).lt("updated_at", cutoff).perPage(100);
await Promise.all(data.map((t) => pawabase.from("tasks").delete(t.id)));
```

Keep concurrency modest (batches of 20 to 50) so you don't hit your table's [rate limit](/database/caching-and-rate-limits). For thousands of rows, do it on a server (a flow, or [SQL](/database/sql-editor)) where it is one operation.

## When to use import instead

| You have | Use |
| --- | --- |
| Up to a few hundred rows from your app | `createMany` |
| A file, or thousands of rows, with updates or duplicates | [Import](/database/import-and-export): validates, upserts, dry run, no events by default |
| A large one-time fix | The [SQL editor](/database/sql-editor), after a backup |

## Progress

For a progress bar, chunk it yourself:

```typescript
for (let i = 0; i < rows.length; i += 50) {
  const batch = rows.slice(i, i + 50);
  const { failed } = await pawabase.from("tasks").createMany(batch);
  setProgress(Math.min(i + 50, rows.length) / rows.length);
  allFailures.push(...failed.map((f) => ({ ...f, index: f.index + i })));
}
```
