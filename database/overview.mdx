The database stores your app's records: tasks, orders, posts, customers. You **define** it once (tables, columns, relations, who can do what) and then **use** it from your app with `pawabase.from("table")`.

This section teaches both halves together. For every topic you will see how to do it in **Studio** (the dashboard), how to do the same thing from **code** so it can be reviewed and repeated, and how your **app** uses the result.

## The two halves

| | You do this | With |
| --- | --- | --- |
| **Define** | Create tables, add columns, set relations and indexes, choose access rules, shape responses | Studio (**Data**) |
| **Use** | Create, read, update and delete records | `pawabase.from("table")` in your app |

Because access rules run on the server for every request, your app can call the database directly from a browser. No backend of your own sits in between.

## A first taste

<CodeGroup>
```typescript TypeScript
const task = await pawabase.from("tasks").create({ title: "Write the docs", done: false });

const { data: open } = await pawabase.from("tasks").eq("done", false).order("created_at", "desc");

await pawabase.from("tasks").update(task.id, { done: true });
await pawabase.from("tasks").delete(task.id);
```

```python Python
task = pb.from_("tasks").create(title="Write the docs", done=False)

open_tasks = pb.from_("tasks").eq("done", False).order("created_at", "desc").execute().data

pb.from_("tasks").update(task["id"], done=True)
pb.from_("tasks").delete(task["id"])
```
</CodeGroup>
