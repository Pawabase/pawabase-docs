The database holds your app's records: tasks, orders, posts. You work with it through `pawabase.from("table")`. Every call is made as the signed-in user, and your **access rules** decide which rows they can read, create, change or delete, so you can call the database straight from a browser.

## Get started

Create a table in the dashboard under **Database** (for example `tasks` with `title` and `done`), then:

<CodeGroup>
```typescript TypeScript
// Create
const task = await pawabase.from("tasks").create({ title: "Write the docs", done: false });

// Read
const { data: open } = await pawabase.from("tasks").eq("done", false).order("created_at", "desc");

// Update
await pawabase.from("tasks").update(task.id, { done: true });

// Delete
await pawabase.from("tasks").delete(task.id);
```

```python Python
task = pb.from_("tasks").create(title="Write the docs", done=False)

open_tasks = pb.from_("tasks").eq("done", False).order("created_at", "desc").execute().data

pb.from_("tasks").update(task["id"], done=True)

pb.from_("tasks").delete(task["id"])
```
</CodeGroup>

## The ideas

| Idea | Meaning |
| --- | --- |
| Table | A collection of records with the same fields. In code you refer to it by name |
| Record | One row, an object with an `id` and your fields. `created_at` and `updated_at` are added for you |
| Access rules | Per table and per action (list, get, create, update, delete). They decide what each user can do |
| Owner | Most apps store the user's id on a record, and a rule says "people can only see their own" |

## A few rules of thumb

- The client sends your filters to the server, so you only download what you need. Filter and page instead of fetching everything.
- Use the signed-in user's `id` as the owner of records, and let a rule enforce it. Never rely on your app code to hide other people's data.
- Treat `created_at` order as your default sort for lists.

## TypeScript types

`createClient` accepts a type that describes your tables, so `from("tasks")` knows its fields:

```typescript
type Task = { id: string; title: string; done: boolean; created_at: string };

const pawabase = createClient<{ resources: { tasks: { Row: Task; Insert: Partial<Task>; Update: Partial<Task> } } }>({ url, apiKey });

const { data } = await pawabase.from("tasks").eq("done", false);   // data: Task[]
```

Column names in `eq`, `order` and `select` are then checked by the compiler.
