**Topology** draws your data model: *resources as tables, the relations between them, and the schemas they use.* Use it to check that a design makes sense, to onboard a teammate, or to find a table nothing connects to.

## In Studio

**Data → Tools → Topology.**

- **Find a resource** highlights one.
- Point at a table or a line to see what it touches: its relations and the schemas it uses.
- **Zoom in**, **Zoom out** and **Fit to width** adjust the view.
- If you have no resources yet it says *Nothing to draw yet*.

Each line is a [relation](/database/relations). If a link you expected isn't drawn, the relation isn't defined (a column holding an id is only a link once a relation names it).

## Use it to review a design

Look for:

- **Orphans:** tables connected to nothing. Intended (a settings table) or forgotten?
- **Missing relations:** an `author_id` column with no `author` relation means nobody can `expand` it.
- **Hubs:** one table connected to everything (usually `users`). Fine, but check its access rules carefully.
- **Cycles** (A→B→A): fine for data, but think about `expand` depth.

## In code

The same information is available from the definitions:

```typescript
const resources = (await m.resources.list()).data;
const edges = resources.flatMap((r) => (r.relations ?? []).map((rel) => `${r.name} -> ${rel.resource} (${rel.name}, ${rel.type})`));
console.log(edges.join("\n"));
```
