## Async usage

```python
async with AsyncPawabase(url, key, project="acme") as pb:
    posts = await pb.list("posts", **{"filter[status]": "eq.live", "per_page": 10})
    created = await pb.create("posts", {"title": "Hi"})
    post = await pb.get("posts", created["id"])
    updated = await pb.update("posts", post["id"], {"status": "live"})
    await pb.delete("posts", updated["id"])
```

All methods are awaitables. Error handling is the same.

## Async patterns

```python
async with AsyncPawabase(url, key, project="acme") as pb:
    # Parallel requests
    import asyncio
    posts, comments = await asyncio.gather(
        pb.list("posts"),
        pb.list("comments")
    )
```

## Using request() for non-standard calls

```python
# Custom path
result = pb.request("GET", "/rest/v1/posts", params={"filter[status]": "eq.live", "select": "id,title"})

# With headers via view
view = pb.as_user(token)
result = view.request("GET", "/rest/v1/posts/post_123")
```

Use `request()` when you need behavior not covered by the five methods, or when calling routes with unusual shapes.

## Errors

Record operations raise `PawabaseError` on failures:

| Status | Typical meaning | Notes |
| --- | --- | --- |
| 400 | Bad request / invalid filter | Check filter syntax. |
| 401 | Unauthenticated | Check key/token. |
| 403 | Forbidden / policy denied | Check policies. |
| 404 | Not found | May mean no access (policies can hide rows). |
| 409 | Conflict | Duplicate or constraint violation. |
| 422 | Validation error | Invalid field values. Check `e.problems()`. |
| 429 | Rate limited | Client retries with backoff. |
| 502/503/504 | Gateway errors | Client retries if conditions met. |
| 0 | Network unreachable | Transport error. |

```python
from pawabase import PawabaseError

try:
    pb.get("posts", "missing")
except PawabaseError as e:
    print(e.status_code)
    print(e.message)
    print(e.code)
    print(e.problems())
    print(e.detail)
```

## Error handling details

```python
from pawabase import PawabaseError

try:
    result = pb.create("posts", {"title": "x"})
except PawabaseError as e:
    if e.status_code == 400:
        # Bad request
        pass
    elif e.status_code == 422:
        # Validation error
        print(e.problems())
    elif e.status_code == 403:
        # Policy denied
        pass
    elif e.status_code == 409:
        # Conflict
        pass
```
