An **invitation** emails someone a link to join an organization with a given role. It works for people who don't have an account yet, and is the usual way to grow a team when sign-ups are closed.

## In Studio

**Users & auth → People → Invitations.**

**Invite people:**

| Field | Meaning |
| --- | --- |
| **Organization** | Which organization they join |
| **Email addresses** | Type an address and press Enter. Add as many as you like |
| **Role** | `viewer`, `member`, `admin` or `owner` |
| **Where the link goes** | An address from [Domains](/auth/redirect-urls) where your application finishes the invitation. Leave empty to use none |

**Pending invitations** lists what is waiting, with **Resend** and **Revoke**.

The email is **Invitation** in [Email templates](/auth/email-templates).

## In your app (a member invites)

<CodeGroup>
```typescript TypeScript
await pawabase.auth.orgs.invite("acme", {
  email: "grace@example.com",
  role: "member",
  redirectTo: "https://myapp.com/accept-invite",
});

const pending = await pawabase.auth.orgs.invitations("acme");
await pawabase.auth.orgs.revokeInvitation("acme", pending[0].id);
```

```python Python
pb.auth.orgs.invite("acme", email="grace@example.com", role="member", redirect_to="https://myapp.com/accept-invite")
pending = pb.auth.orgs.invitations("acme")
```
</CodeGroup>

`redirectTo` must be on your [redirect list](/auth/redirect-urls).

## Accept on your landing page

The email links to your page with a token. The person signs in or up there, then your page accepts:

<CodeGroup>
```typescript TypeScript
const token = new URL(location.href).searchParams.get("token")!;

// the person must be signed in
await pawabase.auth.orgs.acceptInvitation(token);
await pawabase.auth.switchOrg("acme");
```

```python Python
pb.auth.orgs.accept_invitation(token)
```
</CodeGroup>

```tsx
function AcceptInvite() {
  const token = new URLSearchParams(location.search).get("token")!;
  const { user, loading } = useAuth();

  useEffect(() => {
    if (!loading && user) {
      pawabase.auth.orgs.acceptInvitation(token).then(() => navigate("/"));
    }
  }, [loading, user]);

  if (!loading && !user) return <SignInOrUp then={`/accept-invite?token=${token}`} />;
  return <p>Joining…</p>;
}
```

## From a server

The admin client can invite, resend and revoke across all organizations:

<CodeGroup>
```typescript TypeScript
await a.orgs.invite("acme", { email: "new@example.com", role: "member", redirectTo: "https://myapp.com/accept-invite" });
const { data: all } = await a.invitations.list();
await a.invitations.resend(all[0].id, { redirectTo: "https://myapp.com/accept-invite" });
await a.invitations.revoke(all[0].id);
```

```python Python
pb.admin.orgs.invite("acme", email="new@example.com", role="member", redirect_to="https://myapp.com/accept-invite")
invitations = pb.admin.invitations.list()["data"]
```
</CodeGroup>

## Good to know

- An invitation expires. `expires_at` is on each pending invitation; resend to refresh it.
- Accepting makes the person a member with the invited role. The `invitation.accepted` event fires.
- Invitations still work when [sign-ups are off](/auth/sign-up-restrictions); that's the point.
- If the invitee already has an account, they just sign in and accept.
