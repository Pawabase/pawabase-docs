One person, several ways in. **Linking** attaches an extra identity (a Google account, a GitHub account) to a user who already exists, so they can sign in with either and land in the same account with the same data.

## Link an identity

The person must be signed in. Starting the link takes them to the provider and back:

<CodeGroup>
```typescript TypeScript
const url = await pawabase.auth.linkIdentityUrl("google", { redirectTo: "https://myapp.com/settings" });
window.location.assign(url);
```

```python Python
url = pb.auth.link_identity_url("google", redirect_to="https://myapp.com/settings")
# redirect the browser to `url`
```
</CodeGroup>

On return, `getSessionFromUrl()` reports `{ status: "linked", provider: "google" }` and the identity is attached. The provider must be enabled under [Social providers](/auth/social-sign-in), and your return address allowed on the [redirect list](/auth/redirect-urls).

## List and unlink

<CodeGroup>
```typescript TypeScript
const identities = await pawabase.auth.identities();
// [{ id, provider, email, last_sign_in_at }]

await pawabase.auth.unlinkIdentity(identities[0].id);
```

```python Python
identities = pb.auth.identities()
pb.auth.unlink_identity(identities[0]["id"])
```
</CodeGroup>

`user.identities` on the user object shows the same list.

## Don't lock people out

Before unlinking, make sure the person has another way in: a password, another identity, or an email they can use for [codes](/auth/email-codes) or [links](/auth/sign-in-links). A good account page disables **Unlink** when only one method remains.

```tsx
function Connections() {
  const [ids, setIds] = useState<Identity[]>([]);
  useEffect(() => { pawabase.auth.identities().then(setIds); }, []);

  return ids.map((id) => (
    <li key={id.id}>
      {id.provider} — {id.email}
      <button disabled={ids.length < 2} onClick={() => pawabase.auth.unlinkIdentity(id.id)}>Disconnect</button>
    </li>
  ));
}
```

## Events

`identity.linked` and `identity.unlinked` are emitted for [webhooks](/auth/auth-webhooks).

## Merging accounts

If someone accidentally made two accounts, linking can't merge them. Choose the account to keep, move any records to its `id` (a script with the admin client), and delete the other.
