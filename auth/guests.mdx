A **guest** is a real user with no email or password yet. They get an id, a session and their own data. Use guests to let people try the app, add things to a cart or save a draft, then ask them to create an account when they have a reason to.

Turn guests on in the dashboard under **Authentication** (`anonymous_enabled` in `auth.settings()`).

## Start a guest session

<CodeGroup>
```typescript TypeScript
const session = await pawabase.auth.signInAnonymously();
console.log(session.user.id);
```

```python Python
session = pb.auth.sign_in_anonymously()
```
</CodeGroup>

Create it when the person first does something worth saving, not when the page loads, so you do not create thousands of empty guests from visitors who leave straight away. Guest creation is rate limited per address.

## Upgrade to an account

When they sign up, attach the email to the *same* user. Everything the guest created stays theirs.

<CodeGroup>
```typescript TypeScript
const { user, verification_sent } = await pawabase.auth.upgradeAnonymous({
  email: "ada@example.com",
  password: "a long passphrase",
  name: "Ada",
});
```

```python Python
result = pb.auth.upgrade_anonymous(email="ada@example.com", password="a long passphrase", name="Ada")
```
</CodeGroup>

If the project requires confirmed emails, a link is sent (`verification_sent`) and the account is complete once they click it.

Do not call `signUp` for a guest: it creates a different user, and the guest's records stay with the old one.

## Know if someone is a guest

A guest has no email. Use that to decide what to show:

```typescript
const user = await pawabase.auth.getUser();
const isGuest = !user.email;
```

## Limit what guests can do

Guests are real users, so they can do everything a signed-in user can unless your access rules say otherwise. Write rules that need a confirmed email for sensitive actions such as inviting others or exporting data.

## Clean-up

A guest who never returns stays in your user list. If you create many, remove old guests periodically from the dashboard.
