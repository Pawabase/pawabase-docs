## Read the profile

<CodeGroup>
```typescript TypeScript
const user = await pawabase.auth.getUser();
console.log(user.name, user.email, user.avatar_url, user.user_metadata);
```

```python Python
user = pb.auth.get_user()
print(user["name"], user["email"], user["avatar_url"], user["user_metadata"])
```
</CodeGroup>

## Update it

<CodeGroup>
```typescript TypeScript
await pawabase.auth.updateUser({
  name: "Ada Lovelace",
  avatar_url: "https://…/ada.png",
  data: { theme: "dark", notifications: { email: true } },   // merged into user_metadata
});
```

```python Python
pb.auth.update_user(
    name="Ada Lovelace",
    avatar_url="https://…/ada.png",
    data={"theme": "dark", "notifications": {"email": True}},
)
```
</CodeGroup>

`data` is **merged** into `user_metadata`: only the keys you send change.

## Custom data: two places

| Field | Who can change it | Use it for |
| --- | --- | --- |
| `user_metadata` | The person | Preferences, display settings, onboarding state |
| `app_metadata` and `roles` | Only your backend or an administrator | Plans, permissions, anything a rule trusts |

Never base access on `user_metadata`; people can edit it. Use `roles` and `app_metadata`, set from a trusted server.

## An avatar

Upload the image to [storage](/storage/overview), then save its address:

```typescript
const key = `${user.id}/avatar.png`;
await pawabase.storage.from("avatars").upload(key, file);
await pawabase.auth.updateUser({ avatar_url: pawabase.storage.from("avatars").getPublicUrl(key) });
```

## Change the email

<CodeGroup>
```typescript TypeScript
await pawabase.auth.updateUser({ email: "new@example.com" });
```

```python Python
pb.auth.update_user(email="new@example.com")
```
</CodeGroup>

A confirmation link goes to the **new** address, and the email changes when it is clicked. The click lands on a page that calls `confirmEmailChange(token)`. See [verification and resets](/auth/verification-and-resets).

## Change the password

Pass the current password with the new one:

```typescript
await pawabase.auth.updateUser({ current_password: "old", password: "a new long passphrase" });
```

## A profile form

```typescript
async function save(form: { name: string; theme: string }) {
  try {
    const user = await pawabase.auth.updateUser({ name: form.name, data: { theme: form.theme } });
    toast("Saved");
    return user;
  } catch (e) {
    if (e instanceof ValidationError) return e.byField();     // { name: ["too long"] }
    throw e;
  }
}
```

`updateUser` fires `USER_UPDATED`, so components listening with `onAuthStateChange` refresh themselves.
