Several flows work the same way: Pawabase emails a link, the person clicks it and lands on a page in **your app**, and that page finishes the job with the token from the link. Set the landing address with `redirectTo`. It must be on your project's allowed redirect URLs (dashboard, **Authentication**).

## Confirm an email address

If the project requires confirmed emails, `signUp` returns `verificationRequired`. Show a "check your inbox" screen with a resend button.

<CodeGroup>
```typescript TypeScript
await pawabase.auth.resendVerification({ email, redirectTo: "https://myapp.com/verified" });

// On the landing page, with the token from the link:
const session = await pawabase.auth.verifyEmail(token);
```

```python Python
pb.auth.resend_verification(email=email, redirect_to="https://myapp.com/verified")

session = pb.auth.verify_email(token)
```
</CodeGroup>

`verifyEmail` confirms the address and returns a session, so the person is signed in. Read the token from the address your link points to:

```typescript
const token = new URL(window.location.href).searchParams.get("token");
```

## Reset a forgotten password

Two steps: ask for the email, then set a new password on a page of yours.

<CodeGroup>
```typescript TypeScript
// 1. On "Forgot password"
await pawabase.auth.requestPasswordReset({ email, redirectTo: "https://myapp.com/reset" });

// 2. On /reset, with the token from the link
const session = await pawabase.auth.resetPassword({ token, password: newPassword });
```

```python Python
pb.auth.request_password_reset(email=email, redirect_to="https://myapp.com/reset")

session = pb.auth.reset_password(token=token, password=new_password)
```
</CodeGroup>

`requestPasswordReset` always succeeds, whether or not the address has an account, so your message should say "If an account exists, we sent a link." The new session signs the person in.

## Confirm an email change

When someone changes their email with `updateUser({ email })`, a link goes to the **new** address:

```typescript
await pawabase.auth.confirmEmailChange(token);
```

## Make the landing pages robust

- Links expire and work once. If `verifyEmail` or `resetPassword` throws, show "This link has expired" with a button to send a new one.
- Do not show the token in the interface or log it.
- After success, send the person where they were going, not to a generic page.

```typescript
try {
  await pawabase.auth.resetPassword({ token, password });
  navigate("/");
} catch {
  setMessage("This link has expired. Request a new one.");
}
```
