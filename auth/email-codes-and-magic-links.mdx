Passwordless sign-in removes the thing people forget. You send a message, they prove they own the inbox, and they are in. The same flow signs up new people if you allow it.

Turn the methods on in the dashboard under **Authentication**. Check at runtime with `auth.settings()` (`email_code_enabled`, `magic_link_enabled`).

## Email code

The person types a six-digit code. This works well in apps where opening a link would leave the app, such as mobile.

<CodeGroup>
```typescript TypeScript
await pawabase.auth.sendEmailCode({ email: "ada@example.com" });

// Later, when they type the code:
const result = await pawabase.auth.verifyEmailCode({ email: "ada@example.com", code: "123456" });
if (result.status === "mfa_required") await result.verify(authenticatorCode);
```

```python Python
pb.auth.send_email_code(email="ada@example.com")

result = pb.auth.verify_email_code(email="ada@example.com", code="123456")
```
</CodeGroup>

Codes last 10 minutes and allow 5 wrong attempts. Keep the email on screen so people do not retype it. Pass `createUser: false` (`create_user=False`) to sign in existing accounts only. By default an unknown address creates an account.

## Magic link

The person clicks a link and lands back in your app signed in. This works well on the web.

<CodeGroup>
```typescript TypeScript
await pawabase.auth.signInWithMagicLink({
  email: "ada@example.com",
  redirectTo: "https://myapp.com/auth/callback",
});
```

```python Python
pb.auth.sign_in_with_magic_link(email="ada@example.com", redirect_to="https://myapp.com/auth/callback")
```
</CodeGroup>

The link goes to your `redirectTo` page, which must be an allowed redirect URL. In a browser the client reads the session from the address and signs the person in automatically. If you handle the link yourself, pass the token to `verifyMagicLink`:

```typescript
const result = await pawabase.auth.verifyMagicLink(tokenFromUrl);
```

## A complete code flow

```typescript
type Step = "email" | "code" | "done";

async function sendCode(email: string) {
  await pawabase.auth.sendEmailCode({ email });
  return "code" as Step;
}

async function submitCode(email: string, code: string) {
  try {
    await pawabase.auth.verifyEmailCode({ email, code });
    return "done" as Step;
  } catch {
    throw new Error("That code did not work. Check it and try again.");
  }
}
```

## Be kind about errors

- Say "if that address has an account, we sent a code" instead of confirming whether it exists.
- Offer "send a new code" after a short wait. Requests are rate limited.
- Tell people to check spam, and make sure your project's sending address is set up in the dashboard under **Mail**.
