People can manage their own organizations through [the client](/auth/organizations). The admin client lets **you** do it for them: set up a customer's organization, add a user straight in, change a role, or clear old invitations.

## Organizations

<CodeGroup>
```typescript TypeScript
const org = await a.orgs.create("acme", "Acme Inc", { ownerEmail: "ada@example.com", metadata: { plan: "team" } });
const all = await a.orgs.list();
const one = await a.orgs.getOrg("acme");
await a.orgs.update("acme", { name: "Acme Incorporated", metadata: { plan: "enterprise" } });
await a.orgs.remove("acme");
```

```python Python
org = pb.admin.orgs.create("acme", "Acme Inc", owner_email="ada@example.com", metadata={"plan": "team"})
all_orgs = pb.admin.orgs.list()
one = pb.admin.orgs.get_org("acme")
pb.admin.orgs.update("acme", name="Acme Incorporated", metadata={"plan": "enterprise"})
pb.admin.orgs.remove("acme")
```
</CodeGroup>

The `slug` is the organization's short, URL-safe id. `metadata` is free-form data you can use in rules and in your app (plan, region, limits).

## Members

<CodeGroup>
```typescript TypeScript
await a.orgs.addMember("acme", { email: "grace@example.com", role: "admin" });   // an existing user, added directly
await a.orgs.setMemberRole("acme", userId, "member");
await a.orgs.removeMember("acme", userId);
```

```python Python
pb.admin.orgs.add_member("acme", email="grace@example.com", role="admin")
pb.admin.orgs.set_member_role("acme", user_id, "member")
pb.admin.orgs.remove_member("acme", user_id)
```
</CodeGroup>

Roles inside an organization are `viewer`, `member`, `admin` and `owner`.

## Invitations

For people who do not have an account yet, send an invitation:

<CodeGroup>
```typescript TypeScript
await a.orgs.invite("acme", { email: "new@example.com", role: "member", redirectTo: "https://myapp.com/invite" });

const { data: pending } = await a.invitations.list();                    // pending and past invitations, across organizations
await a.invitations.resend(pending[0].id, { redirectTo: "https://myapp.com/invite" });
await a.invitations.revoke(pending[0].id);
```

```python Python
pb.admin.orgs.invite("acme", email="new@example.com", role="member", redirect_to="https://myapp.com/invite")

pending = pb.admin.invitations.list()["data"]
pb.admin.invitations.resend(pending[0]["id"], redirect_to="https://myapp.com/invite")
pb.admin.invitations.revoke(pending[0]["id"])
```
</CodeGroup>

The invitation is mailed with a link to your `redirectTo` page, which must be on the environment's allowed redirect URLs. On that page the person signs in or up, and your app calls [`acceptInvitation`](/auth/organizations#invite-people).

## Onboard a new customer

```typescript
async function onboard(customer: { slug: string; name: string; ownerEmail: string; plan: string }) {
  await a.orgs.create(customer.slug, customer.name, {
    ownerEmail: customer.ownerEmail,
    metadata: { plan: customer.plan },
  });
}
```
