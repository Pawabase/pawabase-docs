These are the events Pawabase emits by itself. Subscribe to any of them with an [event subscription](/automation/events#subscribe-run-something-when-an-event-happens), a flow trigger, or an [outbound webhook](/automation/webhooks). Every event also has the [envelope fields](/automation/events#the-event-envelope) (`id`, `name`, `actor`, `occurred_at`, `request_id`…); the tables below show its **payload**.

## Tables

Each table with **Emit events** on (in its [Settings](/database/table-settings)) emits three events after a successful write.

| Event | When | Payload |
| --- | --- | --- |
| `<table>.created` | A record was added | `resource`, `change: "created"`, `record` (as saved) |
| `<table>.updated` | A record was changed | `resource`, `change: "updated"`, `record` (after the change) |
| `<table>.deleted` | A record was removed | `resource`, `change: "deleted"`, `record` (as it was) |

For a table named `orders`: `orders.created`, `orders.updated`, `orders.deleted`. Write-only fields and vector fields are left out of `record`. See [Table events](/automation/events#table-events).

## Sign-in and accounts

The `actor` of these is usually the person themselves, or `admin` when an operator did it.

| Event | When | Payload |
| --- | --- | --- |
| `user.created` | Someone signed up, accepted an invitation, signed in for the first time with a code, link or social account, or was created by an operator | `user_id`, `email`, `method`, and `anonymous` for guest accounts |
| `user.signed_in` | Every successful sign-in | `user_id`, `method` |
| `user.verified` | An email address was confirmed | `user_id`, `email` |
| `user.updated` | A profile or metadata changed | `user_id`, `changed` (which fields) |
| `user.email_changed` | A new email address was confirmed | `user_id`, `from`, `to` |
| `user.password_changed` | A person chose a new password while signed in | `user_id` |
| `user.password_reset` | A recovery link was used to set a new password | `user_id` |
| `user.mfa_enabled` | A second factor was added | `user_id` |
| `user.mfa_disabled` | A second factor was removed | `user_id` |
| `user.mfa_reset` | An operator cleared someone's second factors | `user_id` |
| `user.passkey_added` | A passkey was registered | `user_id`, `passkey_id` |
| `user.api_key_created` | A person created a personal API key | `user_id`, `key_id` |
| `user.api_key_revoked` | A personal API key was revoked | `user_id`, `key_id` |
| `user.upgraded` | A guest account gained an email address | `user_id`, `email` |
| `user.disabled` | An operator blocked a person | `user_id` |
| `user.enabled` | An operator unblocked a person | `user_id` |
| `user.deleted` | An account was removed | `user_id` |
| `user.data_exported` | A person's data was exported for a data request | `user_id`, `request_id` |
| `user.erased` | A person's data was erased for a data request | `user_id`, `request_id` |
| `session.revoked` | A session ended: signed out, revoked, or all sessions ended | `user_id`, and `session_id` or `scope` |
| `session.reuse_detected` | An old refresh token was replayed, which suggests it was stolen; that session family was ended | `user_id` |
| `identity.linked` | A social or company account was attached | `user_id`, `provider` |
| `identity.unlinked` | A social or company account was detached | `user_id`, `provider` |
| `token_profile.issued` | A token was issued with a [token profile](/auth/token-profiles) | `profile`, `audience` |

`method` tells you how someone signed up or in, for example `password`, `email_code`, `magic_link`, `passkey`, or the social provider.

## Organizations and invitations

| Event | When | Payload |
| --- | --- | --- |
| `organization.created` | An organization was created | `organization`, `user_id` (who made it) |
| `organization.deleted` | An organization was removed | `organization` |
| `invitation.created` | Someone was invited | `organization`, `email`, `role` |
| `invitation.resent` | An invitation was sent again | `organization`, `email`, `role` |
| `invitation.accepted` | An invited person joined | `organization`, `user_id` |

## Machine identities

| Event | When | Payload |
| --- | --- | --- |
| `machine.created` | A [machine identity](/auth/machines) was added | `machine_id` |
| `machine.updated` | It was changed | `machine_id` |
| `machine.deleted` | It was removed | `machine_id` |
| `machine.key_created` | It was given a new key | `machine_id`, `key_id` |
| `machine.key_revoked` | One of its keys was revoked | `machine_id`, `key_id` |

## Agents

| Event | When | Payload |
| --- | --- | --- |
| `agent.run.finished` | An [agent run](/ai/agents/runs) ended, successfully or not | `agent`, `run_id`, `thread_id`, `status` (`done` or `failed`), `output`, `error`, `pending` |
| `agent.run.waiting` | A run stopped to ask a person to approve something | the same, with `status: "waiting"` and `pending` listing the tools it's waiting on |

## Alarms

| Event | When | Payload |
| --- | --- | --- |
| `alarm.state_changed` | An [alarm](/activity/alarms) fired or recovered | `alarm`, `metric`, `from`, `to` (the states), `value` (what was measured) |

Use it to send alerts somewhere other than email, for example a chat channel through a webhook.

## Realtime

| Event | When | Payload |
| --- | --- | --- |
| `realtime.message` | A client published to a channel that a flow's **Realtime message** trigger listens to | `channel`, `event`, `payload`, `user_id` (who published) |

## Your own events

Anything you emit from a flow, a schedule, an inbound hook or the API appears here too, under the name you gave it. See [Emit your own events](/automation/events#emit-your-own-events).

## Examples

| Goal | Subscribe to | Reaction |
| --- | --- | --- |
| Welcome email | `user.created` | A flow that sends a [template](/mail/templates) |
| Keep a CRM in sync | `user.created`, `user.updated`, `user.deleted` | An [outbound webhook](/automation/webhooks) |
| Security alerts | `session.reuse_detected`, `user.mfa_disabled`, `user.disabled` | A flow that emails your team |
| Billing customer per organization | `organization.created` | A flow that calls your payment provider with **HTTP request** |
| Notify a manager when an agent needs approval | `agent.run.waiting` | A flow that sends an email with a link |
| Post alarms to chat | `alarm.state_changed` | A webhook to your chat tool |
| Live order board | `orders.*` | A subscription that publishes to a realtime channel |
