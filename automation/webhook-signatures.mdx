Anyone who knows your URL can post to it. The `Pawabase-Signature` header proves a request came from Pawabase:

```text
Pawabase-Signature: t=1700000000,v1=a1b2c3…
```

`v1` is the hex HMAC-SHA256, keyed with the **Signing secret**, of the text `"<t>.<raw body>"`. Reject requests more than 5 minutes old. Sign over the **raw** body, not re-serialised JSON.

<CodeGroup>
```typescript TypeScript
import crypto from "node:crypto";
import express from "express";

const app = express();

app.post("/hooks/pawabase", express.raw({ type: "application/json" }), (req, res) => {
  const header = req.get("Pawabase-Signature") ?? "";
  const parts = Object.fromEntries(header.split(",").map((p) => p.split("=", 2)));
  const t = Number(parts.t);
  if (!t || Math.abs(Date.now() / 1000 - t) > 300) return res.sendStatus(403);

  const expected = crypto.createHmac("sha256", process.env.WEBHOOK_SECRET!).update(`${t}.`).update(req.body).digest("hex");
  const given = Buffer.from(parts.v1 ?? "", "hex");
  const want = Buffer.from(expected, "hex");
  if (given.length !== want.length || !crypto.timingSafeEqual(given, want)) return res.sendStatus(403);

  const event = JSON.parse(req.body.toString());
  // handle event.event / event.data; ignore a repeated event.id
  res.sendStatus(200);
});
```

```python Python
import hashlib, hmac, json, os, time
from fastapi import FastAPI, HTTPException, Request

app = FastAPI()

def verify(body: bytes, header: str, secret: str) -> bool:
    parts = dict(item.split("=", 1) for item in header.split(",") if "=" in item)
    try:
        stamp = int(parts.get("t", ""))
    except ValueError:
        return False
    if abs(time.time() - stamp) > 300:
        return False
    expected = hmac.new(secret.encode(), f"{stamp}.".encode() + body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, parts.get("v1", ""))

@app.post("/hooks/pawabase")
async def hook(request: Request):
    body = await request.body()
    if not verify(body, request.headers.get("Pawabase-Signature", ""), os.environ["WEBHOOK_SECRET"]):
        raise HTTPException(status_code=403)
    return {"ok": True}
```
</CodeGroup>

## How the signature is made

1. Pawabase takes the current Unix time in seconds, `t`.
2. It builds the text `t` + `.` + the **exact bytes** of the body it sends.
3. It computes the HMAC-SHA256 of that text with the endpoint's **signing secret** as the key, as lowercase hex.
4. It sends `Pawabase-Signature: t=<t>,v1=<hex>`.

To verify, repeat steps 2 and 3 with the body you received and compare with `v1` using a constant-time comparison. Then check `t` is within five minutes of your clock.

## Why each step matters

| Step | Protects against |
| --- | --- |
| Use the **raw body** | JSON re-serialisation changes spaces and key order, and the signature no longer matches |
| **Constant-time** comparison | Timing attacks that guess a signature byte by byte |
| **Five-minute window** | Replays: someone resending a request they captured earlier |
| **Deduplicate on `id`** | Legitimate repeats: retries and redeliveries send the same event again with a fresh signature |

The window checks the time of *this attempt*, so a retry sent hours later still verifies: each attempt is signed when it's sent.

## Framework notes

| Framework | Get the raw body |
| --- | --- |
| Express | `express.raw({ type: "application/json" })` on the webhook route, before any JSON parser |
| Next.js route handlers | `await request.text()` (or `arrayBuffer()`) before parsing |
| Fastify | Add a content-type parser for `application/json` that keeps the buffer |
| FastAPI / Starlette | `await request.body()` |
| Django | `request.body` |
| Flask | `request.get_data()` |

## Several secrets during a rotation

While rotating a secret (see [Webhooks](/automation/webhooks#rotate-a-signing-secret)), check the signature against each secret you currently accept and pass if any matches.

## Receiving in another Pawabase project

To receive Pawabase webhooks in another Pawabase project, create an [inbound hook](/automation/inbound-hooks) with **Verification** set to *Pawabase signature* and **Signature header** `Pawabase-Signature`, using the same secret. Pawabase does the checking for you.

## Troubleshooting

| Symptom | Cause |
| --- | --- |
| Verification always fails | The body was parsed and re-serialised before verifying, the secret differs (copy it again from the endpoint), or the header was read under the wrong name |
| It fails only sometimes | Your server's clock is more than five minutes off. Sync it with NTP. |
| It fails after editing the endpoint | You entered a new signing secret; update the receiver |
| Test deliveries pass, real ones fail | A proxy in front of your receiver changes the body (compression, re-encoding). Verify before anything rewrites it. |
