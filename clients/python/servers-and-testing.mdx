## Servers

- Create one `Pawabase` or `AsyncPawabase` per process. Share it across requests.
- For each request acting on behalf of a user, call `pb.as_user(access_token)` to get a view with `Authorization: Bearer <token>`. The view shares the connection pool.
- Close the client on shutdown.
- Use secret keys only on trusted servers.
- Do not fork a process with an open blocking client.
- Store tokens securely; the SDK does not manage them.

### FastAPI example

```python
from fastapi import FastAPI, Request
from pawabase import AsyncPawabase

app = FastAPI()
pb = AsyncPawabase("https://api.example.com", "pb_sk_...", project="acme")

@app.get("/me")
async def me(request: Request):
    auth = request.headers.get("authorization", "")
    token = auth.replace("Bearer ", "") if auth.startswith("Bearer ") else None
    view = pb.as_user(token)
    return await view.request("GET", "/auth/v1/user")

@app.on_event("shutdown")
async def shutdown():
    await pb.close()
```

## Async patterns

Use `async with AsyncPawabase(...)` for automatic cleanup, or manage manually with `await close()`. All endpoint methods are awaitables. `download()` returns `httpx.Response`.

```python
import asyncio
from pawabase import AsyncPawabase

async def main():
    async with AsyncPawabase(url, key, project="acme") as pb:
        posts = await pb.list("posts")
        print(posts)

asyncio.run(main())
```

## Testing

### Mocking HTTP calls

The SDK creates its own `httpx` clients. Options for testing:

1. Monkeypatch `pb._client.request` or `pb._client.get`
2. Subclass and override `_call()`
3. Use `httpx.MockTransport`

```python
from pawabase import Pawabase
import httpx

pb = Pawabase("https://api.example.com", "pb_pk_...", project="acme")

# Override _call
def fake_call(self, method, path, **kwargs):
    return {"id": "123", "title": "Test"}

pb._call = fake_call.__get__(pb, Pawabase)
```

Or with httpx transport:

```python
import httpx
from pawabase import Pawabase

transport = httpx.MockTransport(lambda req: httpx.Response(200, json={"data": []}))
pb = Pawabase("https://api.example.com", "pb_pk_...", project="acme")
pb._client = httpx.Client(transport=transport, base_url=pb.url, headers=pb.headers)
```

### Function testing

Use `pawabase.testing`:
```python
from pawabase.testing import call, FakeRuntime
from my_func import handler

result = call(handler, {"x": 1})
```

## Deep dive: server patterns

### FastAPI
```python
from fastapi import FastAPI, Request, HTTPException
from pawabase import AsyncPawabase
import os

app = FastAPI()
pb = AsyncPawabase(
    os.environ["PAWABASE_URL"],
    os.environ["PAWABASE_KEY"],
    project=os.environ["PAWABASE_PROJECT"],
    environment=os.environ["PAWABASE_ENV"]
)

@app.middleware("http")
async def add_pawabase(request: Request, call_next):
    token = request.headers.get("authorization", "").replace("Bearer ", "")
    request.state.pawabase = pb.as_user(token)
    response = await call_next(request)
    return response

@app.get("/posts")
async def get_posts(request: Request):
    return await request.state.pawabase.list("posts")

@app.on_event("shutdown")
async def shutdown():
    await pb.close()
```

### Django
```python
# In settings
from pawabase import Pawabase
PAWABASE = Pawabase(url, key, project=project)

# In views
from django.conf import settings
def my_view(request):
    token = request.META.get('HTTP_AUTHORIZATION', '').replace('Bearer ', '')
    pb = settings.PAWABASE.as_user(token)
    return pb.list('posts')
```

### Flask
```python
from flask import Flask, g, request
from pawabase import Pawabase

app = Flask(__name__)
pb = Pawabase(url, key, project=project)

@app.before_request
def setup():
    token = request.headers.get('Authorization', '').replace('Bearer ', '')
    g.pb = pb.as_user(token)

@app.teardown_appcontext
def teardown(exception=None):
    pass  # don't close shared client
```

## Deep dive: testing strategies

### Unit tests with mocks
```python
import unittest
from pawabase import Pawabase
from unittest.mock import Mock

class TestPosts(unittest.TestCase):
    def setUp(self):
        self.pb = Pawabase("https://test.com", "pk_test", project="test")
        self.pb._client = Mock()
    
    def test_list(self):
        self.pb._client.request.return_value = Mock(
            status_code=200,
            content=b'[{"id":1}]',
            json=lambda: [{"id":1}],
            is_error=False
        )
        result = self.pb.list("posts")
        self.assertEqual(result, [{"id":1}])
```

### Integration tests
Use a test environment with test keys. Clean up data after tests.

### Testing async code
```python
import asyncio
from pawabase import AsyncPawabase

async def test():
    async with AsyncPawabase(url, key, project="test") as pb:
        posts = await pb.list("posts")
        assert isinstance(posts, list)

asyncio.run(test())
```

## Deep dive: function testing

```python
from pawabase.testing import call, FakeRuntime
from my_function import handler

# Simple call
result = call(handler, {"name": "test"})

rt = FakeRuntime()
rt.kv.set("key", "value")
result = call(handler, {"name": "test"}, runtime=rt)
```

## Production considerations

- Use environment variables for credentials
- Create one client per process
- Use connection pooling (httpx does this)
- Handle errors gracefully
- Log requests/responses appropriately
- Use secret keys only on servers
- Rotate keys regularly
- Monitor rate limits
- Use timeouts appropriately

## Common patterns

### Retry wrapper
```python
def with_retry(func, max_attempts=3):
    for i in range(max_attempts):
        try:
            return func()
        except PawabaseError as e:
            if i == max_attempts - 1 or e.status_code < 500:
                raise
            time.sleep(2**i)
```

### Batch operations
```python
import asyncio

async def create_many(pb, items):
    tasks = [pb.create("posts", item) for item in items]
    return await asyncio.gather(*tasks)
```
