---

The Python SDK version `0.2.0` has no `admin` namespace like the TypeScript SDK. There are no dedicated methods for creating users, managing roles, managing organizations, or other user administration operations.

## Alternatives

- Use `request()` to call gateway user/admin endpoints directly
- Use `identify(token)` to verify tokens
- Use `as_user(token)` to act as users
- Use management methods where appropriate

```python
from pawabase import Pawabase

with Pawabase(url, "pb_sk_...", project="acme") as pb:
    # Use request for admin endpoints
    users = pb.request("GET", "/platform/v1/users", params={"limit": 10})
```

Exact endpoints depend on the gateway's API.


## Alternative approaches

### Using request() for user management

```python
from pawabase import Pawabase

with Pawabase(url, "pb_sk_...", project="acme") as pb:
    # List users
    users = pb.request("GET", "/platform/v1/users", params={"page": 1, "per_page": 50})
    
    # Create user
    user = pb.request("POST", "/platform/v1/users", json={
        "email": "new@example.com",
        "password": "temp123"
    })
    
    # Get user
    user = pb.request("GET", "/platform/v1/users/user_123")
    
    # Update user
    updated = pb.request("PATCH", "/platform/v1/users/user_123", json={"name": "New Name"})
    
    # Delete user
    pb.request("DELETE", "/platform/v1/users/user_123")
```

### Using run_function for admin operations

```python
# Create admin function
result = pb.run_function("admin-create-user", {
    "email": "user@example.com",
    "role": "member"
})
```

### Using identify

```python
# Verify token and get user info
identity = pb.identify(token)
```

## Notes

The exact endpoints for user administration depend on your gateway version. Check your gateway's API documentation. The Python SDK does not provide typed helpers for these operations.
