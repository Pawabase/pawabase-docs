The Python SDK version `0.2.0` does not implement realtime functionality. There is no `realtime` namespace, no WebSocket client, no methods for channels, presence, history, or publishing. The package does not declare a `realtime` extra.

## What this means

- No `pb.realtime` equivalent exists
- No WebSocket connections are opened
- No automatic reconnection logic
- No channel subscriptions

## Alternatives

Use `@pawabase/client` (TypeScript) for realtime features. If you need realtime from Python, you must implement a WebSocket client against the gateway yourself. This is not supported by the SDK and may break without notice.

For most server-side use cases, polling via `request()` or using flows/events is sufficient.
