## Install

```bash
pip install pawabase
```

For live channels, add the realtime extra: `pip install "pawabase[realtime]"`.

## Create the client

```python
from pawabase import Pawabase

pb = Pawabase("https://api.example.com", "pb_pk_…", environment="production")
```

<Warning>
**Always pass `environment`** with the name of the environment your key belongs to. The Python client sends `development` when you leave it out, and a key from any other environment is then refused with `401 invalid_api_key` (*this key does not belong to environment 'development'*).
</Warning>

Use a **publishable key** (`pb_pk_…`) when acting for a user, and a **secret key** (`pb_sk_…`) from a trusted server only. A secret key bypasses your access rules.

## Sign in

```python
result = pb.auth.sign_up(email="ada@example.com", password="a long passphrase")
if result.verification_required:
    print("Ask them to confirm their email first.")

pb.auth.sign_in_with_password(email="ada@example.com", password="a long passphrase")
```

The session is kept in memory. To keep it between runs of a script, give the client a file:

```python
from pawabase import Pawabase, FileSessionStore

pb = Pawabase(url, key, session_store=FileSessionStore("~/.myapp/session.json"))
```

## Read and write data

```python
tasks = pb.from_("tasks").eq("done", False).order("title").execute().data

task = pb.from_("tasks").create(title="Write the docs", done=False)
pb.from_("tasks").update(task["id"], done=True)
```

`from_` has a trailing underscore because `from` is a Python keyword.

## Async

`AsyncPawabase` has the same methods, awaited:

```python
import asyncio
from pawabase import AsyncPawabase

async def main():
    async with AsyncPawabase(url, key) as pb:
        await pb.auth.sign_in_with_password(email="ada@example.com", password="…")
        page = await pb.from_("tasks").eq("done", False).execute()
        print(page.data)

asyncio.run(main())
```

## Handle errors

```python
from pawabase import AuthenticationError, ForbiddenError, NotFoundError, ValidationError, PawabaseError

try:
    pb.from_("tasks").create(title="")
except ValidationError as e:
    print("Fix the input:", e.message)
except (AuthenticationError, ForbiddenError):
    print("Sign in, or you're not allowed to do that")
except NotFoundError:
    print("No such record, or you can't see it")
except PawabaseError as e:
    print(e.status_code, e.code, e.message, "request", e.request_id)
```

See [Errors](/reference/errors) for every code.

## Files, flows and AI

```python
avatars = pb.storage.from_("avatars")
avatars.upload(f"{user_id}/me.png", open("me.png", "rb"))

quote = pb.flows.invoke("price-quote", sku="A1", quantity=3)   # a flow with an HTTP trigger

answer = pb.ai.chat("chat", "Summarise this ticket: …")          # a model your environment set up
```

## On a server, for one person

Act **for** a signed-in person with the publishable key and their tokens, so your access rules apply to them:

```python
pb = Pawabase(url, PUBLISHABLE_KEY, environment="production")
pb.auth.set_session(access_token=access_token, refresh_token=refresh_token)
```

Use a separate client with a **secret key** for admin work (`pb.admin`, `pb.manage`), never per request.
