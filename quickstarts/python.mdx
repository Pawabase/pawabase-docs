## Install

```bash
pip install pawabase
```

For live channels, add the realtime extra: `pip install "pawabase[realtime]"`.

## Create the client

```python
from pawabase import Pawabase

pb = Pawabase("https://api.example.com", "pb_pk_…")
```

Use a **publishable key** (`pb_pk_…`) when acting for a user, and a **secret key** (`pb_sk_…`) from a trusted server only. A secret key bypasses your access rules.

## Sign in

```python
result = pb.auth.sign_up(email="ada@example.com", password="a long passphrase")
if result.verification_required:
    print("Ask them to confirm their email first.")

pb.auth.sign_in_with_password(email="ada@example.com", password="a long passphrase")
```

The session is kept in memory. To keep it between runs of a script, give the client a file:

```python
from pawabase import Pawabase, FileSessionStore

pb = Pawabase(url, key, session_store=FileSessionStore("~/.myapp/session.json"))
```

## Read and write data

```python
tasks = pb.from_("tasks").eq("done", False).order("title").execute().data

task = pb.from_("tasks").create(title="Write the docs", done=False)
pb.from_("tasks").update(task["id"], done=True)
```

`from_` has a trailing underscore because `from` is a Python keyword.

## Async

`AsyncPawabase` has the same methods, awaited:

```python
import asyncio
from pawabase import AsyncPawabase

async def main():
    async with AsyncPawabase(url, key) as pb:
        await pb.auth.sign_in_with_password(email="ada@example.com", password="…")
        page = await pb.from_("tasks").eq("done", False).execute()
        print(page.data)

asyncio.run(main())
```
