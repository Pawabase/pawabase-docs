**Pawabase Cloud** is the hosted Pawabase. You sign in at the dashboard, create a project, and get a complete backend in a minute or two: a database, sign-in, storage, an API and everything in these docs.

## How it is organised

| Level | What it is |
| --- | --- |
| **Organization** | Owns projects, a team and a plan with its billing. Create one for each company or product you run. |
| **Project** | One complete backend. Each has its own database and address. |
| **Environment** | `development`, `staging`, `production`… inside a project. See [Environments](/environments/overview). |

## Create an organization

1. Sign in and choose **New organization**.
2. Name it. You become its **owner**.
3. Invite your team. See [Team](/cloud/team).

## Create a project

<Steps>
  <Step title="Choose New project">
    Give it a name, such as *Marketing site*. You can rename it later.
  </Step>
  <Step title="Wait a minute">
    The database, sign-in, storage and API are set up for you, and we choose its web address.
  </Step>
  <Step title="Open it">
    Click the project to open its **Studio**. Start with a [quickstart](/quickstarts/javascript).
  </Step>
</Steps>

Search projects by name when you have many.

## Studio

**Studio** is where you build and run a project: tables, users, rules, files, flows, agents, mail, activity and more. Everything in these docs that says "in Studio" means this. Open it from the project's card. Opening Studio needs the **admin** or **owner** role in the organization (see [Team](/cloud/team)).

## Keys and addresses

Each project has an API address and keys for each environment. Create and manage keys under **Settings → API keys** in an environment. See [API keys](/environments/api-keys).

## Pause or restore a project

An admin or owner can **pause** a project that isn't in use and **restore** it later.

## If setting up fails

If a new project fails to set up, its card says so. Choose **Retry**.

## Delete a project

Deleting a project (an admin or owner can) permanently removes it and **all of its data**. You type its name to confirm. It cannot be undone, so take a [backup](/backups/overview) and download it first if there's any chance you'll need it.
