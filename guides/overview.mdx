These guides each build one complete feature, from an empty project to working code, using only what Pawabase ships: the TypeScript and Python clients, Studio, and the HTTP API. Each one says what you'll build, what you need, every step, how to check it works, and what to do when it doesn't.

| Guide | You'll build | Uses |
| --- | --- | --- |
| [An app with signed-in users](/guides/signed-in-app) | A notes app where each person sees only their own notes | Auth, Database, Access rules |
| [Teams and organizations](/guides/organizations) | A multi-tenant app where data belongs to a company, with roles | Organizations, invitations, rules |
| [Private files](/guides/private-files) | Per-user uploads with secure, expiring links, tied to records | Storage, rules, Database |
| [An event-driven workflow](/guides/event-driven-workflow) | Order paid → receipt email, partner webhook, live dashboard | Events, flows, mail, webhooks, realtime |
| [Scheduled jobs](/guides/scheduled-jobs) | A nightly reminder sweep that's safe to re-run | Schedules, flows, mail |
| [A realtime chat](/guides/realtime-chat) | Rooms with messages, history and who's online | Realtime, channel rules |
| [An agent that respects permissions](/guides/agent-with-permissions) | A support assistant that only sees the asker's data and asks before acting | Agents, knowledge, rules |
| [Development to production](/guides/environments-workflow) | A release process with environments, previews and promote | Environments, backups, keys |
| [Production readiness](/guides/production-checklist) | A checklist and runbook for going live and handling incidents | Everything |

## Before you start

- A Pawabase project. Create one in [Pawabase Cloud](/cloud/overview).
- Your project's **API address** and a **publishable key** (and, for server-side steps, a **secret key**) from **Settings → API keys**.
- Node.js 18+ or Python 3.10+ if you follow the code.

```bash
npm install @pawabase/client        # TypeScript / JavaScript
pip install pawabase                 # Python
```

Each guide works in a `development` environment. When you're happy, [promote](/environments/promote) to production.
