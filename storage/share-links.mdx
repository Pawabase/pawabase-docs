title: "Share links"
description: "Temporary, revocable links to one object, created from Studio or the platform API."

A share link lets someone without an account open **one object** until a time you choose. It works whatever the bucket's read policy says, for that object only.

## What a link grants

* One environment, one bucket and one key. Nothing else: not a sibling object, not the bucket listing, not another environment.
* A permission: **view and download**, **view only** (rendered in the browser, never as a download), or **download only** (always an attachment).
* Access until it expires or you revoke it.

The token (`pbs_…`) is 256 bits from a cryptographic random generator. Lookup is by its SHA-256 hash; the token itself is kept only sealed with the platform key so Studio can show the link again to people who manage the bucket.

## From Studio

Open an object in **Storage**, then the **Sharing** tab:

1. Choose how long it should last: 15 minutes, 1 hour, 24 hours, 7 days, or a custom duration (1 minute to 1 year).
2. Choose what it allows.
3. **Create link**, then copy it.

The same tab lists every link for the object with its status (`active`, `expired`, `revoked`), permissions, creation and expiry times and how often it was opened. Active links have **Copy** and **Revoke**.

## From the platform API

```bash
# Create
curl -X POST "$GW/platform/v1/envs/production/buckets/private/shares" \
  -H "apikey: $SK" -H "content-type: application/json" \
  -d '{"key": "7/contract.pdf", "expires_in": 3600, "permissions": "view"}'
```

```json
{
  "id": "01J…",
  "status": "active",
  "permissions": "view",
  "expires_at": "2026-10-15T15:00:00+00:00",
  "token": "pbs_…",
  "url": "https://api.example.com/storage/v1/share/pbs_…"
}
```

| Request | Purpose |
| --- | --- |
| `GET /buckets/{bucket}/shares?key=` | List links (all statuses), newest first |
| `POST /buckets/{bucket}/shares` | Create. `expires_in` is seconds, 60 to 31 536 000 |
| `DELETE /buckets/{bucket}/shares/{id}` | Revoke |

## Opening a link

```
GET /storage/v1/share/<token>
```

No key or sign-in is needed. Ranges, `ETag`, and [image transformations](/storage/transformations) work as they do for any object.

| Status | Meaning |
| --- | --- |
| `200` / `206` | The object |
| `403` | The link is view-only and `?download` was requested |
| `404` | Unknown token, or the object no longer exists |
| `410` | The link expired or was revoked |

Deleting, renaming or moving an object revokes its links, so a new object later created at the same key is not reachable through an old link. Replacing an object keeps its links.

<Warning>
Anyone holding the URL can open the object. Treat a link like a password, prefer short lifetimes, and revoke links you no longer need.
</Warning>
