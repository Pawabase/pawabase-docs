A **share link** lets someone **with no account** open **one file** until a time you choose. It works whatever the bucket's read rule says, for that file only. Use it to send a contract to a client or an export to a partner.

*Anyone with the link can open this object until it expires or you revoke it. It never grants access to anything else.*

## Create one in Studio

1. **Services → Storage**, open the bucket and click the file.
2. Choose the **Sharing** tab.
3. Under **New temporary link**, set **Expires after**: 15 minutes, 1 hour, 24 hours, 7 days, or a custom time (1 minute to 1 year).
4. Set **Allows**:
   - **View and download**: opens in the browser and can be downloaded.
   - **View only**: rendered in the browser, never as a download.
   - **Download only**: always an attachment.
5. Click **Create link**, then copy it.

## Manage links

Below, **Links for this object** lists every link for the file with:

| Column | Meaning |
| --- | --- |
| **Status** | `active`, `expired` or `revoked` |
| **Allows** | What you chose |
| **Created**, **Expires** | The times |
| Opens | How often it was used |

Active links have **Copy** and **Revoke**. A revoked link stops working at once. If there are none, it says **No links yet.**

## What a link grants

- One file, in one environment. Not the bucket's listing, not a sibling file.
- Image [resizing](/storage/images) works through a share link, so you can share a thumbnail.
- The person needs no account and no key.

## When the file changes

| What you do | Effect on its links |
| --- | --- |
| Replace the file (upload to the same key) | Links keep working and show the new file |
| Rename or move it | Links are **revoked** |
| Delete it | Links are **revoked**. A new file later at the same key is never reachable through an old link |

## What the person sees

Opening a link needs no sign-in. An expired or revoked link shows an "expired" response, and an unknown link or deleted file shows "not found".

<Warning>
Anyone holding the URL can open the file. Treat it like a password: prefer short lifetimes, send it over a private channel, and revoke links you no longer need.
</Warning>

## Share links versus signed links

| | Share link | Signed link |
| --- | --- | --- |
| Made in | Studio | Your app or server (`createSignedUrl`) |
| Lasts | Up to a year | Seconds to minutes |
| Revocable | Yes | No (expires) |
| Tracked | Yes (status, opens) | No |
| Best for | People outside your app | Buttons inside your app |
