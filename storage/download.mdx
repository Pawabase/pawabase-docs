## Read a file

<CodeGroup>
```typescript TypeScript
const documents = pawabase.storage.from("documents");

const blob = await documents.download("7/contract.pdf");           // Blob
const text = await documents.downloadText("7/notes.txt");
const notes = await documents.downloadJson("7/notes.json");
const stream = await documents.downloadStream("7/big.zip");        // for large files
```

```python Python
documents = pb.storage.from_("documents")

data = documents.download("7/contract.pdf")        # bytes
text = documents.download_text("7/notes.txt")
notes = documents.download_json("7/notes.json")
```
</CodeGroup>

A file that does not exist, or that you may not see, raises `NotFoundError`. They look the same on purpose.

To offer a download in a browser: `URL.createObjectURL(await documents.download(key))`.

## List files

<CodeGroup>
```typescript TypeScript
const page = await documents.list({ prefix: "7/", limit: 50 });
page.files;       // [{ key, size, content_type, modified }]
page.prefixes;    // the "folders" below the prefix
page.cursor;      // pass it back for the next page; empty on the last

for await (const file of documents.listAll({ prefix: "7/" })) console.log(file.key);
```

```python Python
page = documents.list(prefix="7/", limit=50)
for file in documents.list_all(prefix="7/"):
    print(file["key"])
```
</CodeGroup>

## Delete

<CodeGroup>
```typescript TypeScript
await documents.remove("7/contract.pdf");
```

```python Python
documents.remove("7/contract.pdf")
```
</CodeGroup>

There is no recycle bin. To delete a folder, list the prefix and remove each file.

## A public link

For a **public** bucket, use the address directly, for example in an `<img>` tag:

<CodeGroup>
```typescript TypeScript
const src = pawabase.storage.from("avatars").getPublicUrl("7/avatar.png");
```

```python Python
src = pb.storage.from_("avatars").public_url("7/avatar.png")
```
</CodeGroup>

A private bucket answers "not found" to a public address; use a signed link instead.

## A temporary link

A signed link gives anyone who holds it access to **one file** for a short time, with no sign-in. Use it to let someone download a private file, or to put one in an email.

<CodeGroup>
```typescript TypeScript
const { url, expires_at } = await documents.createSignedUrl("7/contract.pdf", { expiresIn: 600 });
```

```python Python
link = documents.create_signed_url("7/contract.pdf", expires_in=600)
link["url"], link["expires_at"]
```
</CodeGroup>

The default lifetime is 5 minutes. Make a new link each time the page opens instead of saving one. The bucket must have signed downloads turned on in the dashboard, and you must be able to read the file yourself.

## Share with someone who has no account

For links that last days and can be taken back, create a **share link** on a server with a secret key. See [Node.js](/quickstarts/node) for a server client:

```typescript
import { manage } from "@pawabase/client/manage";

const link = await manage(serverClient).buckets.createShare("documents", "7/contract.pdf", {
  expiresIn: 7 * 24 * 3600,
  permissions: "view",
});
await manage(serverClient).buckets.revokeShare("documents", link.id);
```

`permissions` is `view`, `download` or `both`.
