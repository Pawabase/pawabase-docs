Storage keeps your users' files. Files live in **buckets** (like folders with their own rules), and each file has a **key**, its path inside the bucket, such as `7/avatar.png`. You use it through `pawabase.storage` (`pb.storage` in Python).

## Get started

Create a bucket called `avatars` in the dashboard under **Storage** and mark it public. Then:

<CodeGroup>
```typescript TypeScript
const avatars = pawabase.storage.from("avatars");

await avatars.upload(`${user.id}/avatar.png`, file);                 // a File from <input type="file">
const src = avatars.getPublicUrl(`${user.id}/avatar.png`);           // use in <img src>
```

```python Python
avatars = pb.storage.from_("avatars")

avatars.upload(f"{user_id}/avatar.png", open("avatar.png", "rb"), content_type="image/png")
src = avatars.public_url(f"{user_id}/avatar.png")
```
</CodeGroup>

## The ideas

| Idea | Meaning |
| --- | --- |
| Bucket | A named container with its own rules: who can read, who can write, which types and sizes it accepts |
| Key | A file's path in its bucket. Slashes act like folders. Uploading to an existing key replaces the file |
| Public bucket | Anyone with a file's address can see it. Good for avatars and product images |
| Private bucket | Reading needs a signed-in user the rules allow, or a temporary link |
