## Read a file

<CodeGroup>
```typescript TypeScript
const documents = pawabase.storage.from("documents");

const blob = await documents.download("7/contract.pdf");          // Blob
const text = await documents.downloadText("7/notes.txt");          // string
const notes = await documents.downloadJson<Notes>("7/notes.json"); // parsed
const stream = await documents.downloadStream("7/big.zip");        // ReadableStream, for large files
const response = await documents.downloadResponse("7/contract.pdf");
console.log(response.headers.get("etag"), response.headers.get("content-type"));
```

```python Python
documents = pb.storage.from_("documents")

data = documents.download("7/contract.pdf")        # bytes
text = documents.download_text("7/notes.txt")      # str
notes = documents.download_json("7/notes.json")    # parsed
response = documents.download_response("7/contract.pdf")   # httpx.Response
print(response.headers["etag"], response.headers["content-type"])
```
</CodeGroup>

A file that does not exist, or that you are not allowed to see, raises `NotFoundError`. The two look the same on purpose, so a refusal never reveals whether a key exists.

To save a download in the browser, wrap the blob in an object URL:

```typescript
const href = URL.createObjectURL(await documents.download("7/contract.pdf"));
```

## List files

<CodeGroup>
```typescript TypeScript
const page = await documents.list({ prefix: "7/", limit: 50 });
// page.files:    [{ key, size, content_type, modified }]
// page.prefixes: ["7/2025/", "7/2026/"]   (the "folders" below the prefix)
// page.cursor:   pass it back to get the next page; empty on the last

for await (const file of documents.listAll({ prefix: "7/" })) {
  console.log(file.key, file.size);
}
```

```python Python
page = documents.list(prefix="7/", limit=50)
# page["files"], page["prefixes"], page["cursor"]

for file in documents.list_all(prefix="7/"):
    print(file["key"], file["size"])
```
</CodeGroup>

`listAll` follows the cursor for you. On the async Python client, use `async for`.

## Links to a file

### Public bucket

<CodeGroup>
```typescript TypeScript
const src = pawabase.storage.from("avatars").getPublicUrl("7/avatar.png");
// <img src={src} />
```

```python Python
src = pb.storage.from_("avatars").public_url("7/avatar.png")
```
</CodeGroup>

In TypeScript, the URL carries your **publishable** key, which is designed to be public. A secret key is refused, so you cannot leak one into a page by accident. A private bucket answers `404` to a public URL; use a signed URL there.

### Temporary signed link

<CodeGroup>
```typescript TypeScript
const { url, expires_at } = await documents.createSignedUrl("7/contract.pdf", { expiresIn: 600 });
```

```python Python
link = documents.create_signed_url("7/contract.pdf", expires_in=600)
url, expires_at = link["url"], link["expires_at"]
```
</CodeGroup>

The bucket must have `signed_downloads` turned on (see [Buckets](/storage/buckets#settings)). Anyone with the URL can read that one file until it expires, with no sign-in. You must be able to read the file yourself to sign it. The default lifetime is 300 seconds. Keep it short, and make a new link each time the page loads rather than storing one.

## Delete

<CodeGroup>
```typescript TypeScript
await documents.remove("7/contract.pdf");
```

```python Python
documents.remove("7/contract.pdf")
```
</CodeGroup>

There is no recycle bin. To delete a whole "folder", list the prefix and remove each key.

<CodeGroup>
```typescript TypeScript
for await (const file of documents.listAll({ prefix: "7/" })) {
  await documents.remove(file.key);
}
```

```python Python
for file in documents.list_all(prefix="7/"):
    documents.remove(file["key"])
```
</CodeGroup>

## Caching

A bucket's `cache_max_age` tells browsers how long to keep a file. Files have an `ETag` that changes when the file is replaced, so a browser always revalidates correctly. When you replace a file but keep its key, add a version to the URL (`?v=2`) if you need every browser to refetch at once.
