Add options to an image's address and Pawabase serves that version. The original is never changed, so you do not need to make thumbnails yourself.

<CodeGroup>
```typescript TypeScript
const base = pawabase.storage.from("avatars").getPublicUrl("7/me.png");
const thumb = `${base}&width=96&height=96&fit=cover&format=webp`;
```

```python Python
thumb = pb.storage.from_("avatars").transform_url("7/me.png", width=96, height=96, fit="cover", format="webp")
```
</CodeGroup>

```html
<img src="…" width="96" height="96" alt="Ada">
```

## Options

| Option | Values | Meaning |
| --- | --- | --- |
| `width`, `height` | pixels | Output size. Give one and the other follows the ratio |
| `fit` | `contain`, `cover`, `fill` | `contain` fits inside; `cover` fills and crops; `fill` stretches |
| `format` | `webp`, `avif`, `jpeg`, `png`, `auto` | `auto` picks AVIF or WebP when the browser supports it |
| `quality` | 1 to 100 | Compression for lossy formats (80 by default) |
| `rotate` | degrees | Clockwise |
| `crop` | `x,y,width,height` | Crop the original first |

Only picture formats (PNG, JPEG, WebP, GIF, AVIF, BMP) can be resized. Animated images use their first frame.

## Sizes to use

| Where | Options |
| --- | --- |
| Avatar in a list | `width=64&height=64&fit=cover&format=webp` |
| Card picture | `width=480&format=auto` |
| Full-width banner | `width=1600&format=auto&quality=75` |

For sharp pictures on high-density screens:

```html
<img src="…&width=480" srcset="…&width=480 1x, …&width=960 2x">
```

## Good to know

- It works for public links, signed links and share links. The read rule is checked each time, so a resized copy is never shown to someone who could not see the original.
- Resizing must be switched on for the bucket in the dashboard, which also sets the largest size allowed.
- A request outside the allowed sizes is rejected, so use a handful of sizes and reuse them.
