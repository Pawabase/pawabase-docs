Add options to an image's URL and Pawabase renders that variant on the fly. The stored original is never changed. This replaces generating thumbnails yourself.

## Get started

<CodeGroup>
```typescript TypeScript
const base = pawabase.storage.from("avatars").getPublicUrl("7/me.png");
const thumb = `${base}&width=96&height=96&fit=cover&format=webp`;
// <img src={thumb} />
```

```python Python
thumb = pb.storage.from_("avatars").transform_url("7/me.png", width=96, height=96, fit="cover", format="webp")
# <img src="{thumb}" />
```
</CodeGroup>

Resizing works for public URLs, signed URLs and [share links](/storage/share-links). The read rule is checked on every request, so a variant is never shown to someone who could not read the original.

## Options

| Option | Short | Values | Meaning |
| --- | --- | --- | --- |
| `width` | `w` | pixels | Output width |
| `height` | `h` | pixels | Output height |
| `fit` | | `contain`, `cover`, `fill` | `contain` fits inside the box and never enlarges; `cover` fills the box and crops the overflow; `fill` stretches |
| `format` | `f` | `webp`, `avif`, `jpeg`, `png`, `auto` | `auto` picks AVIF or WebP when the browser accepts it |
| `quality` | `q` | 1 to 100 | Lossy quality, 80 by default |
| `rotate` | | -360 to 360 | Degrees clockwise |
| `crop` | | `x,y,width,height` | Crop the original first, in source pixels |

Give only `width` or only `height` and the other follows the image's ratio. Photo orientation is applied. An animated image uses its first frame. Only raster images (PNG, JPEG, WebP, GIF, AVIF, BMP) can be resized; anything else answers `415`, and SVG is never rasterised.

Python's `transform_url` accepts `width`, `height`, `fit` (`cover`, `contain`, `fill`, `inside`, `outside`), `format` and `quality`. In TypeScript, append the options to a URL as shown above, using the long or short names.

## Practical sizes

Pick a few sizes and reuse them, so each is generated and cached once.

| Use | Options |
| --- | --- |
| Avatar in a list | `width=64&height=64&fit=cover&format=webp` |
| Card image | `width=480&format=auto` |
| Full-width hero | `width=1600&format=auto&quality=75` |

For sharp images on high-density screens, use a `srcset`:

```html
<img
  src="…&width=480&format=auto"
  srcset="…&width=480&format=auto 1x, …&width=960&format=auto 2x"
>
```

## Limits per bucket

Resizing can be switched on or off and bounded for each bucket through its `transforms` setting, so a visitor cannot ask for a 20,000-pixel image.

```typescript
await m.buckets.replace("avatars", {
  name: "avatars",
  public: true,
  transforms: { enabled: true, formats: ["webp", "jpeg"], max_width: 2048, max_height: 2048, quality: 80 },
});
```

A request outside the bucket's limits is a `400`, an oversized original is a `413`, and an image that cannot be decoded is a `422`.
