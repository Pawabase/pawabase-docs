## Upload a file

<CodeGroup>
```typescript TypeScript
const documents = pawabase.storage.from("documents");

const stored = await documents.upload(`${user.id}/contract.pdf`, file);
stored.size;           // bytes
stored.content_type;   // "application/pdf"
```

```python Python
documents = pb.storage.from_("documents")

stored = documents.upload(f"{user_id}/contract.pdf", open("contract.pdf", "rb"))
stored["size"], stored["content_type"]
```
</CodeGroup>

Uploading to a key that already exists replaces the file, so repeating an upload is safe.

In a web page, `file` comes from an input:

```typescript
input.addEventListener("change", async () => {
  const file = input.files?.[0];
  if (file) await documents.upload(`${user.id}/${crypto.randomUUID()}`, file);
});
```

## What you can pass

| TypeScript | Python |
| --- | --- |
| `File` or `Blob` | `bytes`, an open binary file, or a `pathlib.Path` |
| `ArrayBuffer`, typed array | `str` (stored as text) |
| `string` (stored as text) | |
| `ReadableStream` | |

The content type comes from the file; pass `contentType` (`content_type`) when it would be guessed wrong.

## Choose keys

- Start with the user's id: `<user id>/avatar.png`. Rules can then say "people write only under their own id".
- Generate names (`crypto.randomUUID()`, `uuid.uuid4()`). Keep the original file name in a record.
- To keep an old version, use a new key each time.

## Big files: upload straight to storage

For large files, your server makes a one-time **signed upload link** and the browser sends the file directly. The link is limited to one key, one type and one size, and expires.

<CodeGroup>
```typescript TypeScript
// On your server
const { url } = await serverClient.storage.from("videos").createSignedUploadUrl(`${userId}/intro.mp4`, {
  expiresIn: 300,
  contentType: "video/mp4",
  maxBytes: 200 * 1024 * 1024,
});

// In the browser, with the url your server returned
await pawabase.storage.from("videos").uploadToSignedUrl(url, file);
```

```python Python
bucket = pb.storage.from_("videos")
link = bucket.create_signed_upload_url(f"{user_id}/intro.mp4", expires_in=300, content_type="video/mp4", max_bytes=200 * 1024 * 1024)
bucket.upload_to_signed_url(link["url"], open("intro.mp4", "rb"), content_type="video/mp4")
```
</CodeGroup>

## Cancel and time out (TypeScript)

```typescript
const controller = new AbortController();
cancel.onclick = () => controller.abort();
await documents.upload(key, file, { signal: controller.signal, timeoutMs: 120_000 });
```

## When an upload is refused

<CodeGroup>
```typescript TypeScript
import { AuthenticationError, PermissionError, PayloadTooLargeError, ValidationError } from "@pawabase/client";

try {
  await documents.upload(key, file);
} catch (e) {
  if (e instanceof AuthenticationError) showSignIn();
  else if (e instanceof PermissionError) show("You can't upload here.");
  else if (e instanceof PayloadTooLargeError) show("That file is too large.");
  else if (e instanceof ValidationError) show("That file type isn't allowed.");
  else throw e;
}
```

```python Python
from pawabase import AuthenticationError, ForbiddenError, ValidationError

try:
    documents.upload(key, data)
except AuthenticationError: ...
except ForbiddenError: ...
except ValidationError: ...
```
</CodeGroup>

The bucket's limits are the real check; test the size and type in the browser as well, to give a quick message.
