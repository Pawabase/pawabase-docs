---
title: "Records"
description: "Find, read, add, change and delete records of your tables from a flow."
icon: "blocks"
---

These blocks read and write your tables, and run a read-only SQL query when you need something the record blocks can't express.

This page documents **7 blocks**. For how flows work, see [Flows](/logic/flows) and the [flow editor](/automation/flow-editor). Values in settings can use templates such as `{{ input.id }}` and `{{ steps.load.output.email }}`; see [Block reference overview](/logic/blocks/overview).

| Block | What it does |
| --- | --- |
| [SQL query](#sql-query) | Runs a parameterised read-only SQL query on the project database. |
| [Transaction](#transaction) | Applies several resource writes atomically. |
| [Create record](#create-record) | Creates a record. |
| [Delete record](#delete-record) | Deletes a record. |
| [Get record](#get-record) | Loads one record; follows `missing` when it does not exist. |
| [List records](#list-records) | Lists records of a resource. |
| [Update record](#update-record) | Updates fields of a record; follows `missing` when it does not exist. |

## SQL query

**Key:** `db.query`

Runs a parameterised read-only SQL query on the project database.

**Continues to:** `next`

| Setting | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `sql` | text | yes |  | SELECT … with ? or $1 placeholders |
| `params` | any JSON |  |  | List of parameter values |
