Compose flows from smaller flows, push slow work to the background, finish a request with the answer you want, and leave a trail in logs and metrics.

This page documents **6 blocks**. For how flows work, see [Flows](/logic/flows) and the [flow editor](/automation/flow-editor). Values in settings can use templates such as `{{ input.id }}` and `{{ steps.load.output.email }}`; see [Block reference overview](/logic/blocks/overview).

| Block | What it does |
| --- | --- |
| [Call flow](#call-flow) | Calls another flow inline and continues with its result. |
| [Queue flow](#queue-flow) | Runs another flow as a background job. |
| [Log](#log) | Writes a line to the run's log (visible in Studio). |
| [Metric](#metric) | Increments a named metric. |
| [Fail](#fail) | Fails the run with an HTTP status and message. |
| [Respond](#respond) | Answers the HTTP request that triggered the run, and ends it. |
