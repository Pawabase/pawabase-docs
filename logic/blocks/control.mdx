Control blocks decide **which path** a flow takes and how it handles waiting and failure. A block with several exits (for example `true` and `false`) leads to different blocks depending on what it decides.

This page documents **11 blocks**. For how flows work, see [Flows](/logic/flows) and the [flow editor](/automation/flow-editor). Values in settings can use templates such as `{{ input.id }}` and `{{ steps.load.output.email }}`; see [Block reference overview](/logic/blocks/overview).

| Block | What it does |
| --- | --- |
| [Delay](#delay) | Waits before continuing. Long waits belong in a delayed job instead. |
| [For each](#for-each) | Runs the `each` branch once per item, then follows `done`. |
| [If](#if) | Follows `true` or `false` depending on a condition. |
| [Merge objects](#merge-objects) | Merges several objects into one (later keys win). |
| [Do nothing](#do-nothing) | Continues the flow without changing state or doing work. |
| [Retry](#retry) | Runs the `attempt` branch until it succeeds, with backoff. |
| [Set variables](#set-variables) | Sets `vars.<name>` for later blocks. |
| [Stop](#stop) | Ends the run without a response. |
| [Switch](#switch) | Follows the handle named by a value, or `default`. |
| [Timeout](#timeout) | Runs an `attempt` branch with a deadline, then follows `next` or `timeout`. |
| [While](#while) | Runs the `body` branch while a condition is true, then follows `done`. |

## Delay

**Key:** `control.delay`

Waits before continuing. Long waits belong in a delayed job instead.

**Continues to:** `next`

| Setting | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `seconds` | number | yes |  | 0 to 300 |

## For each

**Key:** `control.foreach`

Runs the `each` branch once per item, then follows `done`.

**Continues to:** `each`, `done` (follow the one that applies)

| Setting | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `items` | any JSON | yes |  | Template resolving to a list |
| `concurrency` | whole number |  | `1` | 1 to 1 |

## If

**Key:** `control.if`

Follows `true` or `false` depending on a condition.

**Continues to:** `true`, `false` (follow the one that applies)

| Setting | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `condition` | any JSON | yes |  |  |

## Merge objects

**Key:** `control.merge`

Merges several objects into one (later keys win).

**Continues to:** `next`

| Setting | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `objects` | any JSON | yes |  | List of objects |

## Do nothing

**Key:** `control.noop`

Continues the flow without changing state or doing work.

**Continues to:** `next`

This block has no settings.

## Retry

**Key:** `control.retry`

Runs the `attempt` branch until it succeeds, with backoff.

**Continues to:** `attempt`, `next` (follow the one that applies)

| Setting | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `attempts` | whole number |  | `3` | 1 to 10 |
| `base_delay` | number |  | `0.5` | 0 to 30 |

## Set variables

**Key:** `control.set`

Sets `vars.<name>` for later blocks.

**Continues to:** `next`

| Setting | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `values` | any JSON | yes |  | Object of name → value (templates allowed) |

## Stop

**Key:** `control.stop`

Ends the run without a response.

**Ends the run:** nothing follows this block.

This block has no settings.

## Switch

**Key:** `control.switch`

Follows the handle named by a value, or `default`.

**Continues to:** `*`

| Setting | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `value` | text | yes |  | Template whose value picks the branch |
| `cases` | list of string |  |  |  |

## Timeout

**Key:** `control.timeout`

Runs an `attempt` branch with a deadline, then follows `next` or `timeout`.

**Continues to:** `attempt`, `next`, `timeout` (follow the one that applies)

| Setting | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `seconds` | number | yes |  | Maximum time allowed for the attempt branch; 0.001 to 300 |

## While

**Key:** `control.while`

Runs the `body` branch while a condition is true, then follows `done`.

**Continues to:** `body`, `done` (follow the one that applies)

| Setting | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `condition` | any JSON | yes |  | Condition evaluated before every iteration |
| `max_iterations` | whole number |  | `1000` | Safety limit for this loop; 1 to 10000 |
