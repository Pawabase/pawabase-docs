AI blocks use the models, vector fields and agents you set up under **AI**. See [AI in flows](/ai/flows) and [Agents](/ai/agents/overview).

This page documents **7 blocks**. For how flows work, see [Flows](/logic/flows) and the [flow editor](/automation/flow-editor). Values in settings can use templates such as `{{ input.id }}` and `{{ steps.load.output.email }}`; see [Block reference overview](/logic/blocks/overview).

| Block | What it does |
| --- | --- |
| [Run an agent](#run-an-agent) | Hands a job to an agent and continues with its answer. |
| [Answer from my data](#answer-from-my-data) | Answers a question from your own records: searches by meaning, then has a model answer from what it found. |
| [Ask a model](#ask-a-model) | Asks a chat model and returns its answer. |
| [Embed text](#embed-text) | Turns text into vectors. |
| [Add to a knowledge base](#add-to-a-knowledge-base) | Adds text to a knowledge base. The same source added again replaces what was there. |
| [Search a knowledge base](#search-a-knowledge-base) | Finds the passages in a knowledge base that best answer a question. |
| [Search by meaning](#search-by-meaning) | Finds the records closest in meaning to some text (or a vector). |

## Run an agent

**Key:** `ai.agent`

Hands a job to an agent and continues with its answer.

**Continues to:** `next`

| Setting | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `agent` | text | yes |  |  |
| `input` | text | yes |  | What to ask it |
| `thread` | text |  |  | Carry on an earlier conversation |
| `wait` | yes / no |  | yes | Off, the flow carries on at once. Start another flow from the agent.run.finished event |
| `as_user` | yes / no |  | no | Hold its tools to the rules of the user who started this flow |
