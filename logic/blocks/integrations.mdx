These blocks reach outside the flow: other web services, your webhooks and email, the event system and realtime channels.

This page documents **6 blocks**. For how flows work, see [Flows](/logic/flows) and the [flow editor](/automation/flow-editor). Values in settings can use templates such as `{{ input.id }}` and `{{ steps.load.output.email }}`; see [Block reference overview](/logic/blocks/overview).

| Block | What it does |
| --- | --- |
| [Emit event](#emit-event) | Publishes a platform event. |
| [HTTP request](#http-request) | Calls an external HTTP API through an HTTP client. |
| [Read secret](#read-secret) | Reads a secret into the run (never into its trace). |
| [Send webhook](#send-webhook) | Delivers an event to every outbound webhook subscribed to it. |
| [Send email](#send-email) | Sends an email with the environment's mail settings. |
| [Publish to channel](#publish-to-channel) | Publishes a message to a realtime channel. |
