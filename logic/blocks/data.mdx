These blocks work on values already in the run: lists, objects, text, numbers and dates. They don't touch the outside world.

This page documents **19 blocks**. For how flows work, see [Flows](/logic/flows) and the [flow editor](/automation/flow-editor). Values in settings can use templates such as `{{ input.id }}` and `{{ steps.load.output.email }}`; see [Block reference overview](/logic/blocks/overview).
