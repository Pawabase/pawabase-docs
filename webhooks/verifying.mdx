Anyone who knows your endpoint's URL can send it a request. The signature proves a request came from Pawabase. **Verify it before you act on the body.**

## The header

```text
Pawabase-Signature: t=1700000000,v1=a1b2c3d4…
```

- `t` is the Unix time the signature was made.
- `v1` is a hex HMAC-SHA256 of the string `"<t>.<raw body>"`, keyed with the webhook's secret.

Including the time stops replay: reject any request whose `t` is more than 5 minutes from now.

## Steps

1. Read the **raw** request body, as bytes, before any JSON parsing.
2. Split the header into `t` and `v1`.
3. Reject if `t` is more than 300 seconds old or ahead.
4. Compute `HMAC-SHA256(secret, t + "." + body)` as hex.
5. Compare with `v1` using a constant-time comparison.

<Warning>
Sign over the raw body. If your framework parses JSON first and you re-serialise it, spacing and key order change and the signature will not match. Capture the raw bytes (Express: `express.raw`, FastAPI: `await request.body()`).
</Warning>

## Node (Express)

```typescript
import crypto from "node:crypto";
import express from "express";

const app = express();

app.post("/hooks/pawabase", express.raw({ type: "application/json" }), (req, res) => {
  const header = req.get("Pawabase-Signature") ?? "";
  const parts = Object.fromEntries(header.split(",").map((p) => p.split("=", 2)));
  const t = Number(parts.t);

  if (!t || Math.abs(Date.now() / 1000 - t) > 300) return res.sendStatus(403);

  const expected = crypto.createHmac("sha256", process.env.WEBHOOK_SECRET!).update(`${t}.`).update(req.body).digest("hex");
  const given = Buffer.from(parts.v1 ?? "", "hex");
  const want = Buffer.from(expected, "hex");
  if (given.length !== want.length || !crypto.timingSafeEqual(given, want)) return res.sendStatus(403);

  const event = JSON.parse(req.body.toString());
  // handle event.event and event.data; ignore a repeated event.id
  res.sendStatus(200);
});
```

## Python (FastAPI)

```python
import hashlib, hmac, json, os, time
from fastapi import FastAPI, HTTPException, Request

app = FastAPI()

def verify(body: bytes, header: str, secret: str) -> bool:
    parts = dict(item.split("=", 1) for item in header.split(",") if "=" in item)
    try:
        stamp = int(parts.get("t", ""))
    except ValueError:
        return False
    if abs(time.time() - stamp) > 300:
        return False
    expected = hmac.new(secret.encode(), f"{stamp}.".encode() + body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, parts.get("v1", ""))

@app.post("/hooks/pawabase")
async def hook(request: Request):
    body = await request.body()
    if not verify(body, request.headers.get("Pawabase-Signature", ""), os.environ["WEBHOOK_SECRET"]):
        raise HTTPException(status_code=403)
    event = json.loads(body)
    return {"ok": True}
```

## Other languages

The algorithm is the same everywhere: HMAC-SHA256, key = secret, message = `t + "." + raw body`, hex output, constant-time compare. Every language's standard library has HMAC and a constant-time compare (`hash_equals` in PHP, `Rack::Utils.secure_compare` in Ruby, `hmac.Equal` in Go).

## Rotating a secret

Update the webhook with the new secret and deploy your endpoint with the same value. For zero downtime, accept both the old and new secret for a short time: try the new, and fall back to the old.

## When verification fails

| Symptom | Likely cause |
| --- | --- |
| Always fails | You parsed the body before verifying, or the secret differs from the webhook's |
| Fails on some requests | The server clock is off by more than 5 minutes |
| Header missing | A proxy strips unknown headers; allow `Pawabase-Signature` |
