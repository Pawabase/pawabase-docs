## Subscription

Run a flow, or publish to a realtime channel, when an event fires. Same as **Logic → Event subscriptions**.

<CodeGroup>
```python Python
from pawabase_iac import P, Subscription

Subscription("receipt-on-paid", on="orders.updated", run=send_receipt, condition=P.event.data.record.status == "paid")
Subscription("live-orders", on="orders.created", publish_to="orders:live")
```
</CodeGroup>

| Argument | Meaning |
| --- | --- |
| `name` | Letters, digits, dashes |
| `on` | The event name or a pattern: `orders.*` (`*` crosses dots) |
| `run` | The flow (object or name) to run |
| `publish_to` | A realtime channel to publish the event to (instead of `run`) |
| `condition` | Only matching events run it; read the event with `P.event` |
| `enabled`, `description` | |

Use `run` **or** `publish_to`, not both.

## Schedule

Same as **Logic → Schedules**.

<CodeGroup>
```python Python
from pawabase_iac import Schedule

Schedule("nightly-rollup", cron="0 3 * * *", timezone="Africa/Lagos", run=rollup, overlap="skip")
Schedule("poll-provider", interval=600, run=poll)
Schedule("month-end", cron="0 0 1 * *", event="billing.month_end")
```
</CodeGroup>

| Argument | Meaning | Default |
| --- | --- | --- |
| `run` | A flow to run | none |
| `event` | Emit this event on the clock instead | none |
| `cron` | Five fields: minute, hour, day of month, month, day of week | none |
| `interval` | Seconds between runs (10 or more). Use `cron` **or** `interval` | none |
| `payload` | Extra data for the target | none |
| `timezone` | An IANA name such as `Europe/London`. Empty is UTC | UTC |
| `overlap` | `allow` or `skip` while the previous run is still going | `allow` |
| `catch_up` | Run occurrences missed during downtime | `False` |
| `enabled`, `description` | | |

When a schedule fires, the flow receives `{ scheduled_at }` plus your payload. See [Schedules](/automation/schedules) and [Events](/automation/events).
