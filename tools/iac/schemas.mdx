---
title: "Schemas"
description: "Define a reusable data shape once and use it in tables and routes."
icon: "braces"
---

A `Schema` is a named, reusable shape, the same as **Data → Schemas** in Studio.

<CodeGroup>
```python Python
from pawabase_iac import Number, Ref, Schema, String, Table

address = Schema(
    "Address",
    fields=[String("line1", required=True), String("city", required=True), String("country", required=True)],
    description="A postal address",
)

customers = Table(
    "customers",
    fields=[String("name", required=True), Ref("billing_address", schema=address)],
)
```
</CodeGroup>

Use `Ref("column", schema=address)` in a table, a route's input, or as a `response_schema`. See [Schemas](/database/schemas).
