Both live in the package's repository under `examples/` and are validated on every release.

## store

A small shop: tables, a **checkout flow with a loop**, retry and error paths, a receipt flow, **switch-based ticket routing**, subscriptions and a webhook. Read it to learn how flows branch and loop.

## school

A complete **school management system**:

| Part | Count |
| --- | --- |
| Roles | 11 |
| Policies | 22 |
| Tables | 43 |
| Flows | 25 |

Plus routes, subscriptions, schedules, signed payment and SMS webhooks, buckets and mail templates. It deploys through a gateway with a deploy key and passes 67 smoke checks. Read it to learn how a large project is organised across files.

## Run one

<CodeGroup>
```bash Python
git clone https://github.com/Pawabase/pawabase-iac
cd pawabase-iac/examples/store
pip install pawabase-iac
pawabase validate
pawabase emulate
```
</CodeGroup>

Some examples need environment variables for their webhook secrets (`PAYMENTS_HOOK_SECRET=x pawabase validate` is enough to validate).
