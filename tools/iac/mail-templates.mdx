---
title: "Mail templates"
description: "Define email templates with subject, HTML, text and variables; status, categories and folders."
icon: "mail"
---

A `MailTemplate` is the same as a template in **Services → Mail → Templates**.

<CodeGroup>
```python Python
from pawabase_iac import MailTemplate

MailTemplate(
    "receipt",
    subject="Your receipt for order {{ order.id }}",
    preheader="Thanks for your order",
    html="<h1>Thanks, {{ customer.name }}</h1><p>Total: {{ order.total }}</p>",
    text="Thanks, {{ customer.name }}. Total: {{ order.total }}",
    category="orders",
    variables=[
        {"name": "customer.name", "description": "Customer's name", "sample": "Ada"},
        {"name": "order.total", "description": "Order total", "sample": "$19.99"},
    ],
)
```
</CodeGroup>

| Argument | Meaning | Default |
| --- | --- | --- |
| `name` | What flows use to send it | required |
| `subject`, `preheader` | The subject and the preview text (255 characters at most) | `""` |
| `html`, `text` | The bodies. Always give both | `""` |
| `status` | `draft`, `published` or `archived` | `published` |
| `category`, `tags`, `folder` | Organise many templates | empty |
| `variables` | `{name, description, sample}` for each value the template reads | `[]` |
| `description` | A note | `""` |

Send with the `mail.send` block (`template="receipt"`, `data={...}`); see [Mail](/mail/overview).

The visual editor's drag-and-drop *design* is edited in Studio; templates written as HTML here have no visual design until you open them there.
