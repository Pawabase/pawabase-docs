## Schema

A `Schema` is a named, reusable shape, the same as **Data → Schemas** in Studio.

<CodeGroup>
```python Python
from pawabase_iac import Number, Ref, Schema, String, Table

address = Schema(
    "Address",
    fields=[String("line1", required=True), String("city", required=True), String("country", required=True)],
    description="A postal address",
)

customers = Table(
    "customers",
    fields=[String("name", required=True), Ref("billing_address", schema=address)],
)
```
</CodeGroup>

Use `Ref("column", schema=address)` in a table, a route's input, or as a `response_schema`. See [Schemas](/database/schemas).

## Transformer

A `Transformer` reshapes records on the way out. The steps run in a fixed order: omit, pick, set, rename, case.

<CodeGroup>
```python Python
from pawabase_iac import Transformer

public_post = Transformer(
    "public_post",
    pick=["id", "title", "author_id", "created_at"],
    set={"url": "https://example.com/posts/{{ record.id }}"},
    rename={"author_id": "authorId"},
    case="camel",
)
```
</CodeGroup>

| Argument | Meaning |
| --- | --- |
| `omit` | Fields to remove |
| `pick` | Keep only these |
| `set` | Add values; templates read `record.<field>` |
| `rename` | `{old: new}` |
| `case` | `"camel"` or `"snake"` |

Attach it with `Table(..., transformer=public_post)` or on a route. See [Transformers](/database/transformers).
