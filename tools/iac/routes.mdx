A `Route` is a custom endpoint under `/rest/v1` handled by a flow, the same as **Logic → Routes** in Studio.

<CodeGroup>
```python Python
from pawabase_iac import Route, RateLimit

Route(
    "/orders/{id}/pay",
    handler=pay_order,                     # a Flow object, or the flow's name
    method="POST",
    name="Pay an order",
    policy=P.authenticated() & P.permission("orders.pay"),
    rate_limit=RateLimit(10, 60),
)
```
</CodeGroup>

| Argument | Meaning | Default |
| --- | --- | --- |
| `path` | Under `/rest/v1`. `{param}` for path parameters | required |
| `handler` | The flow (or function) that runs | required |
| `method` | `GET`, `POST`, `PUT`, `PATCH`, `DELETE` | `POST` |
| `name`, `description` | The operation name and notes in the API docs | `""` |
| `policy` | Who may call it. Any [policy](/tools/iac/policies) | none (signed-in users) |
| `input_fields` | A list of [fields](/tools/iac/fields) the request body must have | none |
| `input_schema` | A [Schema](/tools/iac/schemas-and-transformers) for the body (instead of fields) | none |
| `response_schema` | A Schema documenting the response | none |
| `transformer` | Reshape the response | none |
| `handler_type` | `flow` or `function` | `flow` |
| `rate_limit` | `RateLimit(limit, window)` | none |
| `cache_ttl` | Seconds to cache `GET` responses | `0` |
| `tags` | Group in the API docs | `[]` |
| `enabled` | `False` answers 404 | `True` |

Your app then calls it with `pawabase.routes.post("orders/42/pay", ...)`. See [Routes](/logic/routes).

## Check who owns what

A route's policy can't know an order is the caller's; the flow must check. Make "load the record **as the caller**, then continue" the first steps of the flow ([Rules on routes](/policies/routes-and-functions#check-who-owns-what-inside)).
