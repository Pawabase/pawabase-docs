Pawabase exposes a remote **Model Context Protocol (MCP)** server at your environment's API address. MCP lets an AI client discover Pawabase tools, read project context, and perform actions permitted by an API key. Ask an assistant to inspect tables, investigate a failed flow, or build a backend definition without copying project details into each prompt.

The connection has three parts:

| Part | Where to find it | Purpose |
| --- | --- | --- |
| MCP URL | **Studio → MCP**, for the selected environment | The remote endpoint, ending in `/mcp/v1` |
| Secret API key | Create one on the same **MCP** page | Authenticates the client and limits its access |
| MCP client | Claude, Codex, Cursor, VS Code, or your own app | Discovers and calls tools |

The endpoint is `https://YOUR-API-ADDRESS/mcp/v1`. Use the exact URL shown in Studio; do not append `/mcp/v1` twice. Send the key in an `apikey` HTTP header. The key belongs to one environment, so a development key cannot access production through a production URL.

## What access means

The key determines which tools the client can discover and call. **Look only** gives read access. **Build with me** allows definition and data changes while excluding users, keys, and secrets. **Everything** grants full environment access. Create a separate key for each client so you can revoke one without interrupting the others. See [keys and permissions](/tools/mcp/keys) for details.

Pawabase checks permissions on every management call. A client may also show its own approval dialog before calling a tool. Treat that dialog as a review step: key scopes are the enforceable limit. Some destructive tools require a `confirm` argument, which an automated client can supply.

## First connection

<Steps>
  <Step title="Select an environment">
    Open your project in Studio and select **development** or another intended environment. Open **MCP** in the environment navigation. Copy the displayed URL.
  </Step>
  <Step title="Create a dedicated secret key">
    Choose **Look only** to inspect safely, or **Build with me** when the assistant needs to create or edit resources. Copy the key when Studio displays it; it is shown only once. Do not use a publishable key.
  </Step>
  <Step title="Add the server to your client">
    Use a guide above. The client needs the MCP URL and an `apikey` header containing the secret key.
  </Step>
  <Step title="Verify and review">
    Ask: “List the tables in my Pawabase development environment.” Check that the client discovers Pawabase tools. Review calls on the Studio **MCP** page or in the [audit log](/activity/audit-log).
  </Step>
</Steps>

<Note>
MCP is for an AI client operating on a project. For a repeatable backend definition committed to Git, use [Infrastructure as Code](/tools/iac/overview).
</Note>
