Claude Code can call Pawabase tools through its remote HTTP MCP connection. Use a development environment and a dedicated **Look only** key first; add a **Build with me** connection when you are ready to let Claude create resources.

## Prepare Pawabase

1. In Studio, select the intended environment and open **MCP**.
2. Create a key named `Claude Code development`. Choose **Look only** or **Build with me**.
3. Copy the key and the full MCP URL, ending in `/mcp/v1`.

Keep the key private. The command below includes it as an argument, so take care with shell history and local Claude configuration. Run it on a trusted machine.

## Add the server

In a terminal with Claude Code installed, run:

```bash
claude mcp add --transport http pawabase https://YOUR-API-ADDRESS/mcp/v1 \
  --header "apikey: YOUR_SECRET_KEY"
```

Replace both placeholders with values from the same Studio environment. The name `pawabase` is how Claude will display this connection. If you have multiple environments, give each one a distinct name such as `pawabase-dev` and `pawabase-prod-read`.

Check that Claude Code registered it:

```bash
claude mcp list
```

Start a Claude Code session and ask: “Using Pawabase, list the tables in this environment and describe their fields.” If the connection is available, Claude should discover the Pawabase tools. On the Studio **MCP** page, check the call history.

## A useful workflow

For inspection, ask Claude to summarize before changing anything:

> Inspect the `orders` table and the `payment-received` flow. Explain the current behavior and propose a change. Do not call write tools yet.

With a **Build with me** key, you can follow with a specific change request. Review the proposed tool call in Claude Code. A client approval prompt is a workflow safeguard; the key scope still controls what Pawabase accepts.

## Change or remove the connection

When rotating a key, remove the old Claude Code server entry, create a new key in Studio, and add the connection again. Revoke the old key under **Settings → API keys**. Use `claude mcp remove pawabase` to remove an entry by name. If a client was configured with a shared key, rotate every place that used it.

See [Claude Code's MCP documentation](https://code.claude.com/docs/en/mcp) for its CLI and configuration scopes, and [troubleshooting](/tools/mcp/troubleshooting) for Pawabase-specific errors.
