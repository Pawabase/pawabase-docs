## Models

| Problem | What to check |
| --- | --- |
| **"No such model"** (404) | The model name is wrong or the model is switched off. See **AI → Models**. |
| **Forbidden** (403) | The model's **Who can use it** doesn't allow this caller. From a browser it must be *Signed-in users* or *Anyone*. |
| **Provider error** (502) | The provider failed or timed out. Set **If it fails, try** to another model of the same kind. |
| **Wrong kind** (400) | A chat model was used for embeddings, or the reverse. |
| **It works in Studio but not in my app** | Your app is using a public key and the model is *Servers only*. |

## Agents

| Problem | What to check |
| --- | --- |
| **"No such agent"** | It is switched off, or your caller isn't allowed to see it. Check **Switched on** and **Who may run it**. |
| **It says it can't find anything** | The agent acts as the person who asked. That person may not be allowed to read the table. Test with a user who can. |
| **It stops and nothing happens** | The status is `waiting`: it asked for approval. Approve or decline in **Try it** or with `decide`. |
| **A change waited even though I turned approval off** | The run read outside content, so changes wait. See [Approvals and limits](/ai/agents/approvals-and-limits#outside-content). |
| **It stopped halfway** | It hit a limit (steps, seconds, tokens or cost). Raise it, or give clearer instructions and fewer tools. |
| **Wrong answers** | Open the run and read the steps. It usually used the wrong tool, had too many tools, or lacked the document. |
| **It repeats itself or loops** | Reduce the tools, make instructions more specific, and lower **Most steps**. |

## Knowledge bases

| Problem | What to check |
| --- | --- |
| **A document stays *pending*** | Wait a few seconds and refresh. If it persists, check the embedding model is working. |
| **A document is *failed*** | Read the reason beside it, fix it, then **Reindex**. Scanned PDFs with no text can't be read. |
| **Search returns nothing relevant** | Add a document that answers the question, or reword it as an answer. Try the question in **Try a search**. |
| **I changed the passage size and nothing changed** | Use **Reindex** on each document. |
| **Someone sees another person's document** | Private documents belong to the person who added them. Documents added from your server without an owner are shared. |

## Connections

| Problem | What to check |
| --- | --- |
| **Check fails** | The key is wrong, expired or lacks permission. Make a new one and reconnect. |
| **Agent can't use an app** | The connection isn't added to the agent as a tool, or **Only these of its tools** leaves it out. |
| **A tool wasn't offered** | The app's key may not allow it. |
