An **embedding** is a list of numbers that captures what a piece of text means. Two texts about the same thing get vectors that sit close together, even when they share no words. That is what makes "how long do refunds take?" find an article titled "Returning an order".

## Get an embedding

You need an **embedding model** added under **AI → Models** (see [Providers and models](/ai/gateway)).

<CodeGroup>
```typescript TypeScript
const vector = await pawabase.ai.embed("embed", "a red ceramic mug");            // number[]
const vectors = await pawabase.ai.embed("embed", ["a red mug", "green tea"]);    // number[][], in the same order
```

```python Python
vector = pb.ai.embed("embed", "a red ceramic mug")
vectors = pb.ai.embed("embed", ["a red mug", "green tea"])
```
</CodeGroup>

Send many texts in one call when you have them. The answers come back in the order you sent them.

`embed` takes the model's alias and one text (giving one vector) or a list (giving one vector per text, in the same order). Like chat models, an embedding model has a rule for who may call it; see [Providers and models](/ai/gateway).

## Compare two texts

Vectors are compared by **cosine similarity**: 1 means the same direction (the same meaning), 0 unrelated.

<CodeGroup>
```typescript TypeScript
function cosine(a: number[], b: number[]) {
  let dot = 0, na = 0, nb = 0;
  for (let i = 0; i < a.length; i++) { dot += a[i]! * b[i]!; na += a[i]! ** 2; nb += b[i]! ** 2; }
  return dot / (Math.sqrt(na) * Math.sqrt(nb));
}

const [question, article] = await pawabase.ai.embed("embed", [
  "how long do refunds take?",
  "Returning an order: money is back on your card within 5 working days.",
]);
cosine(question!, article!);   // high: same topic, no shared words
```

```python Python
import math

def cosine(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    return dot / (math.sqrt(sum(x * x for x in a)) * math.sqrt(sum(y * y for y in b)))

question, article = pb.ai.embed("embed", [
    "how long do refunds take?",
    "Returning an order: money is back on your card within 5 working days.",
])
cosine(question, article)
```
</CodeGroup>

Scores depend on the model. Find a threshold for your data by trying pairs you know are related and pairs you know aren't, rather than picking a number up front.

## Find duplicates

Embed a batch and flag pairs above a threshold:

```python
titles = [t["title"] for t in pb.from_("tickets").is_("closed_at", None).all(max_records=500)]
vectors = pb.ai.embed("embed", titles)
pairs = [
    (titles[i], titles[j])
    for i in range(len(titles)) for j in range(i + 1, len(titles))
    if cosine(vectors[i], vectors[j]) > 0.92
]
```

This compares every pair, which is fine for hundreds of texts. For thousands, store the vectors in a [vector field](/ai/vector-search) and let the database find neighbours with `similar()`.

## Store vectors yourself

A table's **Vector** field can hold vectors you made, as well as ones Pawabase fills in. Send the list of numbers like any other value:

```typescript
const [vector] = await pawabase.ai.embed("embed", [product.description]);
await pawabase.from("products").update(product.id, { embedding: vector });
const { data } = await pawabase.from("products").similar({ vector, limit: 5 });
```

The list must have exactly the field's size.

## You often don't need to do it yourself

- To search your own records by meaning, add a **Vector** field to a table and let Pawabase fill it in each time a record is saved. See [Vector search](/ai/vector-search).
- To let an agent answer from documents, add them to a [knowledge base](/ai/knowledge/overview). Pawabase splits, embeds and searches them for you.

Calling `embed` yourself is for cases those don't cover: comparing two texts, grouping, or storing vectors somewhere else.

## Keep the size consistent

Every embedding model produces vectors of a fixed length, shown as **Vector size** on the model. A vector field in a table must be the same size as the model that fills it. If you switch to a model with a different size, make a new field and fill it again.

## Cost

Embeddings are cheap but add up when you embed a lot. **AI → Usage** shows the tokens and cost of each model so you can see it before the bill does.
