A **connection** is a saved link to an outside service, with your key for it. Agents use connections as tools: an assistant can search your Notion, look up a Stripe customer, open a GitHub issue or search the web.

Open **AI → Connections** to add one. You can search the list, pick an app, paste its key and connect. Your key is sealed on arrival and never shown again.

## Connect an app

<Steps>
  <Step title="AI → Connections → Add a connection">
    Search the list and choose the app. For an app that is not listed, choose **Any MCP server**.
  </Step>
  <Step title="Paste its key">
    Each app tells you where to find its key and what it is called (for example *Personal access token*). Some need no key, and a few ask for extra details such as your shop name.
  </Step>
  <Step title="Check it">
    Choose **Check**. Pawabase calls the app with the key and tells you what it found, or why it could not connect.
  </Step>
  <Step title="Give it to an agent">
    On the agent, **Add → An app** and choose the connection. See [Tools](/ai/agents/tools).
  </Step>
</Steps>

## Apps you can connect

| Group | Apps |
| --- | --- |
| **Work and projects** | Notion, Linear, Jira & Confluence, monday.com, Airtable, Zapier |
| **Code and data** | GitHub, Sentry, Supabase, Neon, Postman, Cloudflare, DeepWiki, Context7 |
| **Customers and sales** | Stripe, Shopify, Intercom, PostHog |
| **The web and research** | Tavily, Exa, Firecrawl, Apify, Hugging Face |
| **Your own** | Any MCP server |

Most apps connect through **MCP**, a standard way for apps to offer tools to AI. Notion has its own connection that can search, read, create and add to pages. **Tavily** and **Exa** are web search services.

## Any MCP server

If an app or your own service offers an MCP server, choose **Any MCP server**, enter its address (it starts with `https://`) and, if it needs one, a key.

## Control what an agent may do with an app

When you add an app to an agent you choose what it may use:

- **Notion**: find pages, read pages, create pages, add to pages.
- **Other apps**: all of its tools, or only some under **Only these of its tools**.

Anything that changes something follows the agent's [approval](/ai/agents/approvals-and-limits) settings.

<Warning>
Give an app key the least permission it needs. For example a read-only token, or a Stripe *restricted key* that can only read customers. The agent can do anything the key allows.
</Warning>

## Keys and secrets

Each connection's key is kept as a [secret](/secrets/overview) in the environment, so it is encrypted, can be rotated, and is never part of anything you export.

## If a check fails

- Check the key is complete and has not expired.
- Make sure the key has permission for what the agent needs.
- Remove the connection and add it again with a fresh key.
