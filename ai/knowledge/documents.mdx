## Add documents in Studio

Open **AI → Knowledge**, choose a knowledge base and add documents any of these ways:

| Way | What to do |
| --- | --- |
| **A file** | Choose or drop a file. PDF, Word (.docx), HTML and plain text are read. |
| **Paste text** | Give it a title and paste the text. |
| **A web page** | Enter the page's address. Pawabase reads its text. |
| **Notion** | Connect Notion under [Connections](/ai/apps/overview), then **Bring in pages from Notion**. Every page you shared with the connection comes in; doing it again brings in only what changed. |

A document can hold up to about 2 million characters of text. A PDF can have up to 2,000 pages.

## Check they are ready

Each document shows a status:

| Status | Meaning |
| --- | --- |
| **pending** | Being read and indexed. This takes seconds. |
| **ready** | Searchable. |
| **failed** | Something went wrong, and the reason is shown. Fix it and use **Reindex**. |

Use **Reindex** on a document to process it again, for example after it failed or after you changed the base's passage size.

## Try a search

On the knowledge base, **Try a search** shows exactly what an agent would find for a question, with the passage, the document it came from and a relevance score. If the right passage is missing, add or reword a document.

## Add and search from your app

<CodeGroup>
```typescript TypeScript
// add text, or a page to read
await pawabase.ai.knowledge.addDocument("help", {
  title: "Refund policy",
  source: "https://example.com/help/refunds",
  text: "Refunds take 5 to 7 business days…",
});
await pawabase.ai.knowledge.addDocument("help", { url: "https://example.com/help/shipping" });

// add a file
await pawabase.ai.knowledge.addFile("help", fileFromInput, { title: "Returns guide" });

// is it ready?
const doc = await pawabase.ai.knowledge.addDocument("help", { text: "…" });
const status = await pawabase.ai.knowledge.document("help", doc.id);   // { status: "ready" | "pending" | "failed", ... }

// search
const hits = await pawabase.ai.knowledge.search("help", "how long do refunds take?", { limit: 3 });
```

```python Python
pb.ai.knowledge.add_document("help", title="Refund policy", source="https://example.com/help/refunds",
                             text="Refunds take 5 to 7 business days…")
pb.ai.knowledge.add_document("help", url="https://example.com/help/shipping")

with open("returns.pdf", "rb") as f:
    pb.ai.knowledge.add_file("help", f, filename="returns.pdf", title="Returns guide")

doc = pb.ai.knowledge.add_document("help", text="…")
status = pb.ai.knowledge.document("help", doc["id"])

hits = pb.ai.knowledge.search("help", "how long do refunds take?", limit=3)
```
</CodeGroup>

Each search result has:

| Field | Meaning |
| --- | --- |
| `text` | The matching passage |
| `title` | The document's title |
| `source` | Where it came from (its source or title) |
| `document_id` | The document |
| `score` | How relevant it is; higher is better |

### Who can do what

- **Searching** follows the knowledge base's **Who can search it?** rule. Your servers can always search.
- **Adding** from a server adds to the shared knowledge base, or, with an owner, for one person. A signed-in user adding a document adds one that only they can find.
- A person's private documents never appear for anyone else.

## Remove or replace

Delete a document in Studio to remove it and everything searchable made from it. To replace it, add it again with the same `source`.

## Keep Notion in step

Run **Bring in pages from Notion** again whenever your Notion pages change. Unchanged pages are skipped, so it is quick.
