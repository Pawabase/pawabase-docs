You build an agent in **AI → Agents**. Nothing to install, no code to write.

<Note>
You need at least one **chat model** first. If you have none, **AI → Agents** says "First, add a chat model" and links to where to add one. See [Providers and models](/ai/gateway).
</Note>

## Make it

<Steps>
  <Step title="Open AI → Agents → Make your first agent">
    Give it a **name** (for example *Support assistant*) and a short description of what it is for. Choose the model it **thinks with**.
  </Step>
  <Step title="Tell it what to do">
    Under **What should it do?**, write instructions in plain words.

    > You help customers with their orders. Be brief. Never promise a refund; ask a person to approve it.

    Good instructions say who the agent is helping, what it should do, what tone to use, and what it must never do.
  </Step>
  <Step title="Give it something to use">
    Under **What it can use**, choose **Add** and pick tables, flows, documents or apps. See [Tools](/ai/agents/tools).
  </Step>
  <Step title="Choose who may run it">
    Under **Who may run it**, pick an access rule. By default only your own servers can run it. To let the people who use your app run it, choose a rule such as *signed-in users*.
  </Step>
  <Step title="Save and try it">
    Open **Try it**, type a message and watch it work. Every step appears as it happens: its words, each tool it uses, and anything waiting for your answer.
  </Step>
</Steps>

## The settings

| Setting | What it does |
| --- | --- |
| **What should it do?** | The instructions. Be specific; you can edit them at any time. |
| **What it can use** | Tools and knowledge bases. |
| **Who may run it** | The access rule for running the agent. |
| **Hold it to each person's own access** | On by default: the agent only reads and changes what the person who asked could. Turn it off only for agents that work for your own servers. |
| **Wait for a person after reading anything from outside** | On by default: after reading a web page or other outside content, changes wait for approval. |
| **Most steps / seconds / tokens / cost** | The limits for one run. Defaults are 12 steps and 120 seconds. |
| **Before it changes anything** | Whether changes always wait for approval, never wait, or follow each tool's own setting. |
| **Switched on** | Turn the agent off without deleting it. |

## Improve it by watching it

The **Runs** list shows everything the agent has been asked, from Studio, your app or a flow. Open a run to see each step and what it cost. When an answer is wrong, the steps usually show why: it looked in the wrong table, lacked a document, or the instructions were vague. Edit and try again.
