A chat model answers a question. An **agent** goes further: it can look things up in your tables, run your flows, search your documents, use other apps, and take several steps to finish a job, all while staying inside the rules you set.

Examples:

- A **support assistant** that finds a customer's orders, answers from your help articles and, with a person's approval, issues a refund.
- A **sales helper** that reads your products, looks up a customer in Stripe and drafts a reply.
- A **research assistant** that searches the web and summarises what it found into a new page in Notion.

## What an agent is made of

| Part | What it is |
| --- | --- |
| **Model** | The chat model that does the thinking. |
| **Instructions** | What it should do and how, written in plain words. |
| **Tools** | The things it may use: tables, flows, web pages, apps, other agents. See [Tools](/ai/agents/tools). |
| **Knowledge** | Documents it may search and quote. See [Knowledge bases](/ai/knowledge/overview). |
| **Who may run it** | An [access rule](/policies/overview), so you decide who can use it. |
| **Limits** | The most steps, seconds, tokens and money one run may use. See [Approvals and limits](/ai/agents/approvals-and-limits). |

## How it behaves

- **It acts as the person who asked.** When a signed-in user runs the agent, its tools follow *that person's* access rules. If the user cannot read an order, the agent cannot read it for them. You can switch this off for agents that run on behalf of your own servers.
- **It asks before it changes things.** Reading is free; adding, changing or deleting waits for a person to approve, unless you tell a tool never to ask.
- **It is cautious with the outside world.** After it reads something it did not get from you, such as a web page, anything it changes afterwards waits for a person. This protects you from a page that tries to tell the agent what to do.
- **It stays on budget.** Every run has limits. When one is hit, the run stops and says so.
- **Everything is recorded.** Each run keeps its question, steps, tools, answer, tokens and cost.

## Run it from anywhere

| From | How |
| --- | --- |
| **Studio** | Open the agent and use **Try it** to chat and watch each step. |
| **Your app** | `pawabase.ai.agents.run(...)`, streaming or in the background. See [Run an agent from your app](/ai/agents/run-from-app). |
| **A flow** | Start a flow when a run finishes or needs approval. See [Runs and history](/ai/agents/runs). |

## Before you start

You need a **chat model** (see [Providers and models](/ai/gateway)). To let it search documents you also need an **embedding model**.
