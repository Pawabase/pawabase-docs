Every time an agent is asked something, Pawabase keeps a **run**: the question, each step, every tool used, the answer and what it cost.

## Where to find runs

- **AI → Agents → an agent → Runs** lists everything that agent has been asked, from Studio, your app or a flow.
- **AI → Agents → Runs** lists runs across all agents.

Filter by agent, by status (`running`, `waiting`, `done`, `failed`) or by conversation. Open a run to read it.

## What a run shows

| Part | What you see |
| --- | --- |
| **Who and where** | The person or server that asked, and whether it came from Studio, your app or a flow |
| **Question and answer** | What was asked and what came back |
| **Steps** | Each model turn and tool call, in order, with whether it worked or was refused |
| **Waiting** | What it asked permission for, and who decided |
| **Outside content** | A note when the run read something from outside, and so held its changes for approval |
| **Cost** | Steps, input and output tokens, and dollars (when the model has prices set) |

Someone running an agent in your app sees what happened but not the raw inputs and outputs of each tool; only your servers see those.

## Conversations

Runs that share a **thread** are one conversation. The agent remembers recent messages in a thread, up to the last 60. See [Run an agent from your app](/ai/agents/run-from-app#continue-a-conversation).

## Start a flow when a run ends

Pawabase announces what happens to a run as [events](/automation/events), so a flow can react:

| Event | When |
| --- | --- |
| `agent.run.finished` | A run ended, successfully or not |
| `agent.run.waiting` | A run stopped and needs a decision |

Typical uses:

- Send a Slack-style notice to a manager when a run is waiting for approval.
- Save the answer of a long background run to a table when it finishes.
- Email a summary when a scheduled agent run ends.

Create an [event subscription](/automation/events) for the event and pick the flow to run.

## Clean up

Delete a run from its page when you no longer need the record.

## Check usage and cost

**AI → Usage** shows calls, tokens and cost for the models your agents use. Set a **Most cost** limit on each agent so one run cannot surprise you.
