Two ideas make AI easy to change later:

- A **provider** is a company or server that runs models (OpenAI, Anthropic, Google Gemini, Mistral, Groq, or any server that speaks the OpenAI format), together with your key for it.
- A **model** is a *name your app asks for*, like `chat` or `embed`, that points at one of a provider's models.

Because your app only knows the name, you can move `chat` from one provider's model to another in Studio and nothing in your code changes.

## Connect a provider

Open **AI → Providers → Add provider**, choose one and paste its key. For your own server, enter its address instead.

| Provider | Chat | Embeddings | Notes |
| --- | --- | --- | --- |
| OpenAI | yes | yes | |
| Anthropic | yes | no | Anthropic has no embedding models. Text conversations and tool use work; images are not supported. |
| Google Gemini | yes | yes | |
| Mistral | yes | yes | |
| Groq | yes | no | |
| OpenAI-compatible | yes | yes | Ollama, vLLM, LM Studio, OpenRouter, Together, DeepSeek, xAI and any other server that speaks the OpenAI format. |

The key you paste is sealed on arrival. Studio only ever shows that a key is **stored**. To change it, paste a new one. Switching a provider **Off** stops every model on it.

<Note>
An OpenAI-compatible address must be reachable from the internet. Addresses on a private network are refused, so a model definition cannot be used to reach machines it should not.
</Note>

## Add models

Open **AI → Models → Add models**. Studio asks the provider which models your key can use and lists them under **Chat** and **Embeddings**. Tick one or more. They get simple names (`chat`, `embed`, `chat-2`…) that you can change.

If you want a model the provider does not list, such as a fine-tune or a brand-new release, add it by name under **Use a model that is not listed**.

Open a model to change:

| Setting | What it does |
| --- | --- |
| **Model** | Which of the provider's models answers. Your app keeps using the same name. |
| **Who can use it** | See below. |
| **Instructions** | A system prompt added to every conversation that has none of its own. |
| **Temperature and other defaults** | Used when a request doesn't set them. A request's own value always wins. |
| **Vector size** | For embedding models: how many numbers each vector has. [Vector fields](/ai/vector-search) must match. |
| **Price in / out** | Dollars per million tokens, so usage can show a cost. Optional. |
| **If it fails, try** | Another model of the same kind to fall back to when this one's provider is down or rate limiting. |

## Who can use a model

| Choice | Meaning |
| --- | --- |
| **Servers only** (default) | Only your servers, using a secret key. |
| **Signed-in users** | People signed in to your app can call it directly from the browser. |
| **Anyone** | Anyone with your public key. Use sparingly: you pay for every call. |
| **A rule you wrote** | Any [access rule](/policies/overview), for example only users with a paid role. |

<Warning>
Keep models on **Servers only** unless a browser really needs to call one. A model open to the browser can be used by anyone who can use your app, and the cost is yours.
</Warning>

## Try a model

**AI → Playground** lets you chat with any model in Studio, change its settings and see the tokens used, before you write any code.

## See what it costs

**AI → Usage** shows calls, tokens, errors, speed and cost for each model over time. Every call is recorded with its model, token counts, time and cost, but **never with what was asked or answered**.
