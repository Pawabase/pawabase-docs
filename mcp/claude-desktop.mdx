Claude Desktop can use Pawabase's public remote MCP endpoint through a **custom connector**. This connector is associated with your Claude account and may also be available in Claude on the web and other Claude surfaces. It connects from Anthropic's infrastructure, so the Pawabase URL must be reachable from the public internet.

## Prepare the Pawabase connection

1. Select the intended environment in Studio and open **MCP**.
2. Create a dedicated secret key. **Look only** is a good first choice.
3. Copy the full MCP URL and the key shown once.

For a self-hosted installation behind a private network, use [Claude Code](/mcp/claude-code) from a machine with network access or review [self-hosted options](/mcp/self-hosted). A Claude remote connector cannot reach a server available only on your laptop or VPN.

## Add a custom connector

In Claude Desktop or Claude on the web:

1. Open **Customize → Connectors**.
2. Choose **Add custom connector**. In an organization, an owner may need to add it under **Organization settings → Connectors** first.
3. Enter a name such as `Pawabase development` and the MCP URL from Studio.
4. For authentication, use the connector's fixed **Request headers** setting. Add header name `apikey` and your secret key as its value. If Claude offers sign-in options, select the option for no user sign-in and use the fixed header.
5. Save the connector, then connect or enable it for a conversation using the **+ → Connectors** control.

Ask Claude: “What tables are in my Pawabase environment?” Confirm the calls appear on the Studio **MCP** page. If the connector fails before listing tools, inspect the URL, key, and whether the endpoint is publicly reachable.

## Organization access

A fixed request header is a shared credential for anyone permitted to use that connector. On Team or Enterprise plans, review the connector's access before adding a **Build with me** key. Prefer a dedicated **Look only** key for a broadly available connector; give a narrower group a separate connection for writes.

## Rotate the key

Create a new key in Studio, replace the connector's `apikey` value, test it, then revoke the previous key under **Settings → API keys**. If an organization owner manages the connector, they must update its fixed header.

Claude's [custom connector guide](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp) describes the current connector menus and network requirements. See [troubleshooting](/mcp/troubleshooting) for Pawabase response errors.
