VS Code can expose a Pawabase MCP server to its AI chat. Studio generates a workspace configuration using `.vscode/mcp.json`. VS Code's newer Copilot agent configuration may also use an `mcpServers` object in a user or workspace MCP config; follow the format your installed VS Code version asks for.

## Get the Pawabase values

In Studio, select an environment and open **MCP**. Copy the URL ending in `/mcp/v1` and create a secret key for VS Code. Start with **Look only**; use **Build with me** when the agent needs to make changes.

## Configure a VS Code workspace

Create `.vscode/mcp.json` in your workspace:

```json
{
  "servers": {
    "pawabase": {
      "type": "http",
      "url": "https://YOUR-API-ADDRESS/mcp/v1",
      "headers": {
        "apikey": "YOUR_SECRET_KEY"
      }
    }
  }
}
```

Replace the URL and key with values from the same Studio environment. Open VS Code's MCP server view or chat tool picker and start the `pawabase` server if prompted. Ask: “Using Pawabase, list the tables in this environment.” Check the Studio **MCP** call history.

If your installed Copilot agent asks for an `mcpServers` configuration instead, use its current schema with the same Pawabase URL and `apikey` header:

```json
{
  "mcpServers": {
    "pawabase": {
      "type": "http",
      "url": "https://YOUR-API-ADDRESS/mcp/v1",
      "headers": {
        "apikey": "YOUR_SECRET_KEY"
      }
    }
  }
}
```

Use the location and schema shown by your editor's **Add MCP server** flow; do not place both formats in one file.

## Keep the key local

Do not commit a real key in `.vscode/mcp.json`. Ignore the file or use a supported secret prompt or variable substitution in your installed VS Code version. A key in a shared workspace file is available to everyone with repository access. Create a separate **Look only** key for production rather than reusing a development write key.

For changing VS Code configuration formats, see the [official MCP configuration reference](https://code.visualstudio.com/docs/agents/reference/mcp-configuration) and [server management guide](https://code.visualstudio.com/docs/agents/run/manage-mcp-servers). See [troubleshooting](/mcp/troubleshooting) for endpoint and key errors.
