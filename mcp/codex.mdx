Codex reads MCP server configuration from its `config.toml`. Configure Pawabase once for the Codex CLI and IDE extension, then give the server a secret key through an environment variable. Use a key scoped to the environment and work you intend to allow.

## Get the Pawabase values

Open your project environment in Studio, then **MCP**. Copy the URL ending in `/mcp/v1` and create a dedicated secret key. Choose **Look only** to start, or **Build with me** for development tasks. The secret is displayed once.

## Configure the server

Add this section to `~/.codex/config.toml`:

```toml
[mcp_servers.pawabase]
url = "https://YOUR-API-ADDRESS/mcp/v1"
env_http_headers = { apikey = "PAWABASE_API_KEY" }
default_tools_approval_mode = "writes"
```

`env_http_headers` maps the HTTP header `apikey` to the **name** of an environment variable. Do not put the key itself in this TOML value. Set the variable in the environment that launches Codex:

```bash
export PAWABASE_API_KEY="YOUR_SECRET_KEY"
codex
```

For an IDE extension, make sure the application that launches Codex inherits the same variable. A variable exported in one terminal may not be present in a GUI app started separately. Use your operating system's secret or environment management if needed.

Use `default_tools_approval_mode = "writes"` to ask Codex for approval before write actions when supported by your installed version. The Pawabase key remains the enforceable permission boundary; use **Look only** when writes must be impossible.

## Verify it

In Codex, inspect available MCP servers or ask: “Use Pawabase to list the tables in my development environment.” Confirm a call appears on the Studio **MCP** page. If no tools appear, check that the variable was present when Codex started, the URL and key belong to the same environment, and the key has suitable scopes.

## Multiple environments

Use distinct names and variables:

```toml
[mcp_servers.pawabase_dev]
url = "https://DEV-API-ADDRESS/mcp/v1"
env_http_headers = { apikey = "PAWABASE_DEV_KEY" }

[mcp_servers.pawabase_prod]
url = "https://PROD-API-ADDRESS/mcp/v1"
env_http_headers = { apikey = "PAWABASE_PROD_READ_KEY" }
```

Name the production server clearly and give it a **Look only** key. Tell Codex which connection to use in the prompt. Rotate by setting a new variable value and revoking the old key in Studio.

For Codex configuration details, see [OpenAI's MCP documentation](https://developers.openai.com/codex/mcp/). For Pawabase errors, see [troubleshooting](/mcp/troubleshooting).
