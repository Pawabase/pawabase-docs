Most rules are made from a handful of ready-made checks. They read better than building the same thing with **Compare values**, and they are the forms Pawabase understands best.

## The checks

| In the builder | Fill in | Passes when |
| --- | --- | --- |
| **Is signed in** | yes / no | The caller is signed in. *no* means "must be anonymous" |
| **Has role** | one or more roles | The caller has any of those roles |
| **Has permission** | one or more permissions | The caller has that permission, or the wildcard `*` |
| **Owns the record (field)** | a column; default `owner_id` | That column equals the caller's id |
| **Uses a secret key** | nothing | A secret key (or Studio) made the request |
| **Signed in with 2FA** | nothing | The session completed a second step |
| **Key has scope** | a scope | The API key carries it |
| **Caller kind is** | a kind, such as `user` | The kind of caller matches |

## The same checks in the rule picker

| In the picker | Equivalent |
| --- | --- |
| **Signed-in users** | Is signed in |
| **Record owner (owner_id)** | Owns the record (`owner_id`) |
| **Signed in with 2FA** | Signed-in users **and** Signed in with 2FA |
| **Secret keys & Studio** | Uses a secret key |
| **Users with role…** | Has role |
| **Users with permission…** | Has permission |
| **Owner via field…** | Owns the record (that column) |
| **Keys with scope…** | Key has scope |
| **Anyone (public)** / **Nobody** | Always / never |

## Permission names must match

**Has permission** compares text. If a role grants `posts:write`, type `posts:write`, not `posts.write`. Pick one separator for your project and use it everywhere ([Roles](/auth/roles)).

## Why prefer them

- **Database filters.** An **Owns the record** rule on a list becomes "only the caller's rows" in the database query, so only they are read and pages and counts are exact.
- **Clarity.** *Has role admin* explains itself.
- **Fewer mistakes.** The builder makes them correctly.

## Custom owner columns

Not every table's owner is called `owner_id`. Use **Owner via field…** (or **Owns the record (field)**) and type `author_id`, `customer_id` or whichever column holds the person.

Where several people may act (the author **or** an editor), combine: **Any of:** Owns the record (`author_id`); Has role `editor`.
