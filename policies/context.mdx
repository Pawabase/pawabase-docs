A rule reads facts about the request by **path**: a word starting with `$`, then dots. `$auth.user_id` is the caller's id. This page is the complete list.

If a path points at something that doesn't exist (a column the record doesn't have, `$record` on a create), the value is **missing**, which behaves like `null`: comparisons with it are false (see [Values and paths](/policies/values-and-paths)).

## `$auth`: who is calling

| Path | Meaning | Anonymous callers |
| --- | --- | --- |
| `$auth.authenticated` | `true` when signed in | `false` |
| `$auth.user_id` | The caller's id | `null` |
| `$auth.email` | Their email | `null` |
| `$auth.roles` | A list of role names | `[]` |
| `$auth.permissions` | A list of permission strings | `[]` |
| `$auth.org` | The organization (slug) the session is acting in | `null` |
| `$auth.org_role` | Their role in it: `viewer`, `member`, `admin`, `owner` | `null` |
| `$auth.aal` | `aal1` (password) or `aal2` (second factor) | `null` |
| `$auth.kind` | What kind of caller: `user`, `service`, `anonymous` | `anonymous` |
| `$auth.session_id` | The session's id | `null` |
| `$auth.claims` | The whole token's claims, for custom [attributes](/auth/sign-up-form-and-attributes) | `{}` |

Custom attributes you marked "include in the access token" appear in `$auth.claims`, for example `$auth.claims.plan`. See [Token profiles](/auth/token-profiles) and [Attributes](/auth/sign-up-form-and-attributes).

## `$record`: the row

| Path | Meaning |
| --- | --- |
| `$record.<column>` | Any column of the row being read, changed or deleted |

Available on `get`, `update` and `delete` (the existing row). On `list` it describes each candidate row. On `create` there is no record yet: use `$input`.

## `$input`: what is being sent

| Path | Meaning |
| --- | --- |
| `$input.<field>` | A field in the body of a create or update |
| `$input` | The whole body |

Use it to constrain values: allow only certain statuses, cap a quantity, forbid setting an owner other than yourself.

## `$request`: the request

| Path | Meaning |
| --- | --- |
| `$request.method` | `GET`, `POST`… |
| `$request.path` | The path |
| `$request.ip` | The caller's address |
| `$request.params` | Path parameters |
| `$request.query` | Query-string values |

## `$credential`: the API key

| Path | Meaning |
| --- | --- |
| `$credential.role` | `publishable`, `secret`, or none |
| `$credential.is_service` | `true` for secret keys and Studio |
| `$credential.scopes` | The key's scopes (a list) |
| `$credential.key_id` | The key's id |

## `$env`

The environment's name (`development`, `production`…). Rarely needed; useful for a rule you share across environments but want looser in development.

## `$object`: storage rules only

| Path | Meaning |
| --- | --- |
| `$object.key` | The whole file key, `avatars/usr_abc/photo.jpg` |
| `$object.segments` | The key split on `/`: *all of: avatars; usr_abc; photo.jpg* |
| `$object.segments.0` | The first segment (lists are indexed from 0) |
| `$object.action` | `read`, `list`, `write`, `update`, `delete` |

## `$event`: subscription conditions

| Path | Meaning |
| --- | --- |
| `$event.name` | The event name |
| `$event.data` | The event's payload |

In a subscription's **Only when…**, you can also read the event envelope as `$input.event.…`. See [Events](/policies/events).

## `$now`

The current time (UTC). Compare it with a date column:

- **Compare values:** `$record.publish_at` **is at most** `$now`

## Quick reference: which exist where

| | Table `list` | Table `get/update/delete` | Table `create` | Storage | Channel | Route | Subscription |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `$auth` | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| `$record` | ✓ (each row) | ✓ | – | – | – | – | – |
| `$input` | – | update: ✓ | ✓ | – | – | ✓ | ✓ (event) |
| `$object` | – | – | – | ✓ | – | – | – |
| `$credential`, `$request`, `$env`, `$now` | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
